### 真模型评测与调优

- **第一次跑**：9/10 通过，但每题都有失败的工具调用，有 5 题超过 10 次调用。原因分三类：
  - 评测脚本并发执行同一步里的多个工具调用，互相覆盖了特征树（浏览器本来就是按顺序执行）。
  - 内核问题：
    - 拉伸出来的圆柱，上下两圈边各被切成两段圆弧，选「杯底那一圈」时 `expect: 1` 对不上；
    - 选择器会选中圆柱面上的接缝线；
    - 阵列个数不能写参数；
    - 表达式外面多套一层引号时报错。
  - 缓存：状态拼在系统提示词里，模型每改一次树，后面约 1.2 万 token 的工具定义和历史都不能复用缓存，命中率只有约 6%。
- **修完以后**：10/10 通过，每题 6–10 次调用。除了评测环境本来就不支持的 `look`，没有失败的调用。缓存命中 99%，10 题共 $0.019，原来是 $0.17。非思考模式只有 8/10，所以保持思考模式。
- **浏览器实测**：
  - 让它做带 C 形把手的马克杯：7 次调用一次做对，最后用 `look` 看图确认。
  - 手动把外径改成 90 后，让它「把手上移 10、杯口倒 R0.5」：
    - 它从消息里的快照读到了新外径；
    - 先用 `inspect` 确认杯口有内外两圈边，再只给外圈倒角。
  - 这一轮花了约 $0.002。

FeatureTree 的第一版已经可以完整跑通：18 节互动课、9 个由 OpenCascade 内核烘焙的拆解案例（7 个零件、2 个装配）、2 种练习、18 个命令的工具图鉴、24 张概念卡，以及覆盖 96 节课的学习路径和到期复习。类型检查、lint、17 个测试和生产构建都通过；主要页面在浏览器里逐一点过，亮暗两套主题、手机宽度（375px）也看过。

### 做了什么

### 互动课（18 节）

每节课 4–7 步，一步一个概念。视角自动转到这一步该看的地方，任务在 3D 里完成，易错处先猜再揭晓，最后是 3 道带解释的小测和要点总结。

| 轨 | 课 |
| --- | --- |
| T0 公共地基（4） | 坐标系与视图 · 基准面 · 正投影：三视图与第一角、第三角 · 剖视 |
| T1 参数化零件（8） | 从草图到实体 · 几何约束与自由度 · 旋转 · 阵列与镜像 · 圆角与倒角 · 先圆角还是先抽壳 · 扫掠与放样 · 特征树、父子关系与拓扑命名 |
| T2 装配与机构（1） | 零件的 6 个自由度与配合 |
| T4 面向制造的设计（3） | 3D 打印：悬垂与摆放方向 · 钣金：折弯、K 因子与展开 · 注塑：拔模与分型线 |
| T5 曲线曲面（2） | 曲率梳与 G0 / G1 / G2 连续 · 斑马纹 |

几处值得一提的实现：

- 「几何约束与自由度」用 FreeCAD 的草图求解器 planegcs（WebAssembly）实时数自由度，冗余约束和冲突约束都由求解器判出来。
- 「先圆角还是先抽壳」的两个盒子是内核烘焙的真几何，横剖开对比转角壁厚；参数调到哪一档会失败也是内核算出来的。
- 「正投影」把零件放进玻璃盒：轮廓先投到盒面，再展开成三视图；第一角（国标）和第三角可以切换，虚线靠射线检测判断哪些棱线被挡住。

零件拆解页的能力：

- 回滚、播放特征树，回滚时可以打开「后续特征」的幽灵预览。

### 工程

- `app/src/three/` 是轻量 CAD 视口引擎，包括：
  - Z 轴朝上、按需渲染。
  - 材质颜色全部从主题 token 读取，所以亮暗两套主题自动跟随。
  - HTML 视图方块和坐标轴指示。
  - 剖切：截面用切面色填实。
  - 烘焙模型的加载和面状态着色。
- `models/ftbake` 是烘焙器，有三个机制：
  - 用 `# @step` 标记切出每一步的代码。
  - 参数网格全组合烘焙。
  - 用几何投影判定每个面是新生成、修改还是没变；在内核 spike 里，和 OCCT 自己的操作历史在 1,694 个面上只差 1 处。全量烘焙约 93 秒，产出 14 MB。
- 设计系统基于 jim-uiux：
  - 强调色是「工程蓝」，3D 场景用的颜色都是独立的语义 token。
  - 设计守卫测试会拦住裸色值、12px 以下的字号和手写弹层，并检查对比度。

### 已知局限

- **T3「工程图与公差」没有互动课。** 课程大纲里有 8 节，目前只在学习路径里列出。剖视、三视图在 T0 里讲了，标注和公差还没做。
- **还没有端到端测试。** 测试只覆盖逻辑和设计守卫；交互是手动在浏览器里点的，课程的后几步没有每一步都在手机宽度下看过。
- **入口 JS 偏大**（gzip 177 KB）。课程大纲、命令表和术语都打在入口里；以后可以按路由拆开。
- **oxlint 有 React Compiler 警告，不影响运行：**
  - 拆解页在渲染时读 ref。
  - 课程页和练习页在 effect 里 setState。
  - 几个课程文件导出了非组件。
- **「被修改」的面有时大片标橙。** 例如马克杯最后加把手根部圆角时，整个杯身外表面都算「修改」。这符合 OCCT 的语义（面的边界变了），但第一次看可能意外；图例里有说明。
- **小的视觉问题：**
  - 3D 打印课第一步零件显得偏小。
  - 图鉴里「切除」演示有一条分层接缝线。
  - 温湿度计底壳的筋在整体视图里较小，要靠「聚焦」看。
- **有几处文案要找真软件核对：**
  - Fusion 的默认向上轴：现在写的是「可在偏好里设置」，没有断言默认值。
  - SOLIDWORKS 图纸设置里「第一视角 / 第三视角」的中文译名。
  - ISO 投影符号的朝向。
  - 剖面线规则：现在只给了规则，没给出标准编号。
- **首页的马克杯动画是程序化几何，不是烘焙模型**，所以和拆解页的马克杯在细节上略有不同。
