## 为什么

- 工程图是工业设计、机械制图课的经典交付物。课上考两件事：看图想出立体，按立体画出图。三维模型和二维图对照着看，最能练这个能力。
- 现在工作台只能导出 STEP、STL 和代码，没有图纸。学习者做完一个零件，拿不出一张「能交给加工」的图。
- 图纸的尺寸可以直接来自特征树里的参数，比如 `pcd`、`bolt`。参数改了，图纸跟着变，正好展示参数化的意义：设计意图从模型一路传到图纸上。
- 「尺寸标在模型上」做完以后，模型上和图纸上用的是同一组尺寸。在 3D 里看懂的那个「⌀90（pcd）」，到图纸上还是它。

## 已确认（2026-11-07，均按建议）

**D1. 投影法：第一角还是第三角？**

- A. 只做第一角投影（GB/T 14692、ISO E 法）：主视图在左上，俯视图在主视图下面，左视图在主视图右边。
- B. 缺省第一角，可以切换到第三角（美国 ANSI 常用）。
- C. 两种都做，第一次打开时让学习者选。

建议（用户未反对）：A，第三角以后再加。国内教材和考试都用第一角。先做一种，把排布、线型、尺寸做对。以后加切换也不难，只是换视图位置和标题栏里的投影符号。

**D2. 工程图放在哪里？**

- A. 视图区上方加一个切换「3D | 工程图」，图纸占满原来的大视图，右侧的对话、参数照常。
- B. 右侧面板加一个「工程图」标签页。
- C. 单独开一个页面。

建议（用户未反对）：A。图纸需要大面积，右侧面板太窄，放不下 A4 横版。切到图纸后，还能一边改参数一边看图纸变化。单独开页面会和对话割裂开。

**D3. 用公式算出来的尺寸，图纸上标不标？**

模型上的尺寸只标三种：参数、参数乘系数、直接写的数（见尺寸规格的「显示哪些」）。用公式算出来的不标在模型上，例如瓶子轮廓点的 `R-11.2`。图纸不一样，它要能拿去加工，缺了尺寸就做不出来。

- A. 图纸上也标，只写算出来的数值，不写公式和名字；排在其他尺寸后面，放不下时列进「没放下」。
- B. 和模型上一样，不标。

建议：A。例子：瓶身轮廓第 5 个点在 `R-11.2`，模型上不标它，图纸上标「18.8」。这样加工的人拿到图就能做，学习者在模型上看到的仍然只有设计尺寸。

**D4. 第一版导出哪些格式？**

- A. SVG，加上用浏览器打印成 PDF（A4 或 A3 横版，打印样式里去掉界面）。
- B. 在 A 的基础上再加 DXF（给激光切割、CAD 软件用）。
- C. 只在屏幕上看，先不导出。

建议（用户未反对）：A。SVG 直接从画图的数据写出来；PDF 用浏览器打印，不加新依赖。DXF 要自己写直线和圆弧的格式（OpenCascade 和 replicad 都没有现成的），放到第二期。

## 探针结果

全部只用 replicad，在 Node 里跑：

- **消隐投影能用**：`drawProjection(shape, "front" | "top" | "left" | …)` 底层是 `HLRBRep_Algo` 加 `HLRBRep_HLRToShape`，这个 wasm 里都有。
  - 40×30×10 的块中间穿一个 ⌀10 的孔：每个视图 3–18 ms。
  - 法兰盘（⌀120，中心孔，6 个螺栓孔）：每个视图 6–49 ms。
  - 轴测图用 `new ProjectionCamera(位置, 方向)`，8 ms。
- **输出的看不见的线要去重**：
  - 俯视图里，底面的外框和孔的下沿都算作看不见的线，但它们和看得见的线完全重合。
  - 主视图里，孔的两个圆是侧对着我们的，被输出成和上下轮廓重合的折线。
  - 不去重的话，图上会出现实线、虚线叠在一起。必须把和看得见的线重合的那部分看不见的线删掉。
- **坐标是投影平面上的坐标**：
  - 主视图里 Z 朝上，到 SVG 里成了 −y，需要统一翻转。
  - 视图可以直接用 `toSVGPaths()` 输出，圆弧会保留成 `A` 命令。
- **视图名称不可靠**：
  - replicad 里有 `front`、`back`、`left`、`right`、`top`、`bottom`，但方向不一致：`front` 是 [0, −1, 0]，`right` 却是 [−1, 0, 0]，`left` 是 [1, 0, 0]。看不出这到底是视线方向，还是指向观察者的方向。
  - 实现时每个视图都用 `ProjectionCamera` 写明观察者的位置、视线方向和图上的右方向。
  - 用一个不对称的零件（一角缺一块）写单元测试，确认左视图确实是从左边看过去的。

## 建议的做法

| 问题 | 建议 | 理由 |
| --- | --- | --- |
| 在哪里算 | Worker 里，新请求 `drawing`。只在工程图打开时算，参数改动后防抖 150 ms | 消隐要几十毫秒，不能卡住界面；没打开就不算 |
| 视图 | 主视图、俯视图、左视图，第一角排布；轴测图可以打开或关掉，放在右下 | 和教材一致 |
| 视图方向 | 主视图：观察者在 −Y，朝 +Y 看，也就是前视基准面，和 3D 视图方块上的「前」一致。俯视图：观察者在 +Z。左视图：观察者在 −X，放在主视图右边 | 学习者在 3D 里看到的「前」，和图纸上的主视图是同一面 |
| 线型 | 看得见的线用粗实线 0.5；看不见的线用细虚线 0.25（线段 3、间隔 1）；中心线用细点画线；尺寸线用细实线 | 按 GB/T 4457.4 和 GB/T 17450 简化 |
| 中心线 | 孔和圆柱在视图里是圆的，画十字中心线；在侧面看成矩形的，画轴线 | 制图课必讲，读图也靠它 |
| 图纸和比例 | A4 横版放得下就用 A4，否则用 A3。比例从优先系列里挑能放下的最大一个（1:1、1:2、1:5、2:1、5:1…） | 按 GB/T 14690 的优先比例 |
| 标题栏 | 简化版：零件名、比例、材料（缺省「未注」）、单位 mm、投影符号、日期、图号（自动）。拆件以后，零件名写这个零件的名字 | 按 GB/T 10609.1 简化；设计者一栏留空 |
| 字体 | 尺寸和标题栏用站点已有的思源黑体子集 | 国标要求长仿宋，但那要再下载一套字体；先用现有的，以后再说 |
| 尺寸从哪里来 | 用尺寸规格的 `dimensions()`：每个尺寸带特征、字段路径、种类、数值、来源（参数、系数、直接写的数、公式算的）、白话名、标签文字和三维几何。工程图只负责把这些尺寸放进视图、投影、排开 | 一套尺寸，模型上和图纸上一致，改参数两边一起变 |
| 图纸自己加的 | 只加两样：总长、总宽、总高三条总体尺寸（从包围盒算，尺寸模型里没有它们）；D3 选 A 时，公式算出的尺寸只写数值 | 总体尺寸是图纸必须有的；其他一律来自尺寸模型 |
| 重复孔 | 沿用尺寸模型给孔的一条引线（孔径、个数、深度、沉孔合在一起）。图纸上按制图课的写法，把个数写在前面：「6×⌀8 均布」；节圆直径（`⌀90`）也来自尺寸模型 | 和教材写法一致 |
| 多个零件 | 拆件以后，每个零件一张图，可以在零件之间切换；装配图放到以后 | 加工、打印都是按零件来的 |
| 刻字 | 第一版不画刻字（算图时临时压缩刻字特征），图上加一句注「文字见模型」 | 刻字有上千条边，消隐会很慢；图纸上的文字通常也只是一个注 |

## 尺寸怎么标（第一版的规则）

尺寸全部来自 `dimensions()`，这里只规定怎么把它们放到视图里。

1. **选哪个视图**：每个尺寸只放进一个视图，按它的三维几何来挑：
   - **直线尺寸**（两端点 a、b）：尺寸方向 b − a 必须和视线垂直，也就是在视图平面里。候选视图中，优先挑 a、b 都落在看得见的线上的视图；还分不出就按主视图、俯视图、左视图的顺序。
   - **直径、半径、节圆、个数**：挑能看到整圆的视图，也就是视线平行于圆的法向的那个。
   - **引线**（孔、圆角、倒角、字号）：孔挑孔口显示成圆的视图；圆角、倒角挑引出点所在的边看得见的视图。
   - **角度**：挑圆弧所在平面平行于视图平面的视图。
   - **没有合适的视图**（例如斜面上的尺寸，三个视图里都是斜着的）：第一版不标，列进「没放下」；第二期加斜视图。
2. **投影**：
   - 三维点按这个视图的相机投影到图纸上，再乘以比例。
   - 尺寸模型给出的「向外偏」方向投影以后，决定尺寸线往哪一边偏。
   - 每个尺寸离轮廓 8 mm，同一侧再有尺寸就再往外 7 mm（都按图纸上的毫米算）。
3. **标签**：
   - 用尺寸模型的 `text`。
   - 右上角有开关「显示参数名」：关时只写数值（`80`、`⌀90`），和真实图纸一样，缺省关；开时写成 `L = 80`。
   - 公式算出的尺寸（D3 选 A 时）始终只写数值。
4. **去重**：
   - 同一个尺寸（同一个 `id`）只出现一次。
   - 不同特征标出的尺寸，如果数值相同、两端也重合（例如两个特征都定了同一个宽），只标 `priority` 高的那个。
5. **总体尺寸**：
   - 总长标在主视图下方；
   - 总高标在主视图右侧（左视图在右边时就标在左侧）；
   - 总宽标在俯视图右侧；
   - 和某个尺寸模型给出的尺寸重合时（例如总长就是 `L`），只保留尺寸模型的那个，因为它带参数名。
6. **放不下时**：
   - 两个尺寸打架，就把后标的那个往外挪一层，按 `priority` 从高到低标。
   - 最多三层；再放不下就不标，在图下列出「有 N 个尺寸没放下」。
   - 第一版不做复杂的避让。

## 分期

- **第一期（本方案）**：
  - 三视图和可选的轴测图；
  - 看不见的线（已去重）、中心线；
  - 尺寸模型里的尺寸加总体尺寸；
  - 标题栏；多零件时每个零件一张图；
  - 导出 SVG，打印成 PDF。
- **第二期**：
  - 全剖视图和半剖视图（复用剖视功能的切法，画剖面线）；
  - 局部放大图、斜视图；
  - DXF 导出；
  - 第三角投影切换；
  - 自己拖动尺寸的位置。
- **以后**：
  - 装配图和明细栏；
  - 公差（尺寸公差、形位公差 GD&T）、表面粗糙度、技术要求；
  - 读图练习：给出三视图，让学习者在 3D 里找到对应的面。

## 验收

- **单元测试**：
  - 带孔方块：三视图里看得见的边数和外形尺寸都对。去重以后，俯视图里没有看不见的线，主视图里正好两条竖直的虚线（孔）。
  - 法兰：俯视图里，6 个孔各有十字中心线；尺寸里有「6×⌀8 均布」和「⌀90」，都放在俯视图里。
  - 同一组尺寸：图纸上每个尺寸的 `id` 都来自 `dimensions()`，除了总体尺寸；改参数 `pcd` 以后，模型上和图纸上的 ⌀90 一起变成新值。
  - 视图选择：矩形的宽标在草图平面正对着的那个视图；拉伸距离标在侧面能看到它的视图；斜面上的尺寸进「没放下」。
  - 第一角排布：俯视图在主视图正下方，左视图在主视图正右方，三个视图之间长对正、高平齐、宽相等。
  - 视图方向：一个一角缺一块的方块，在主视图、俯视图、左视图里，缺口都出现在应该出现的那个角。
  - 比例：120 mm 的法兰在 A4 上选 1:1，600 mm 的零件选 1:5。
  - 拆件模型：每个零件一张图，标题栏写零件名。
  - 导出的 SVG 能用浏览器打开，带 `viewBox`，单位是 mm。
- **冒烟测试**：
  - 打开小盒子模型，切到「工程图」，看到三个视图和标题栏；
  - 改参数 L 以后，总长尺寸跟着变；
  - 导出 SVG 能下载。
- **性能**：四个现成模型的图纸，在参数改动后 300 ms 内更新。

## 风险

- **消隐的结果有时是碎的**：同一条线会被拆成好几段，相切的地方也会多出线（比如圆角的切线）。按 GB 规定，相切的过渡线不画，或者画成细实线。第一版：把相切边（`Rg1Line`）画成细实线；去重和连接的容差取 0.01 mm。
- **自动尺寸的排布**：这里最容易做出「对但难看」的图。第一版只承诺不重叠、不漏掉关键尺寸，不追求和老师画得一样。
- **跟着尺寸规格变**：尺寸模型改了字段，图纸要跟着改。两边共用同一个类型定义，单元测试会挡住不一致。
- **曲面多的零件**（杯子的把手、扫掠件）：轮廓线来自 `OutLine`，有时不连续。只验收现成模型，其他零件尽力而为。
- **工作量**：尺寸来自尺寸模型，图纸这边主要是消隐、视图、投影和排布，比原来估的小。时间紧的话，先上线「三视图 + 标题栏 + 总体尺寸」，尺寸模型里的尺寸第二批再上。
