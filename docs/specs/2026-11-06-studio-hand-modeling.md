## 待讨论

1. **「新建」放在哪**
   - 甲：特征树底部一个「＋ 新建特征」，点开分组菜单。
   - 乙：视图顶部一排工具栏，类似 SolidWorks 的 CommandManager、Onshape 的顶栏。
   - 丙：两个都要。
   - **建议甲。** 特征就列在特征树里，新建也从这里出，位置最好找。视图顶部已经放着提示条和测量面板，再加十几个图标会挤掉 3D 视图，聊天栏在右侧时更明显。工具栏可以第二期再加。
   - 不管选哪个，标注卡片上都加两个快捷按钮：「在这个面上画草图」「在这里打孔」（见下文）。
2. **新特征什么时候进特征树**
   - 甲：点菜单就按默认值插进去，卡片就是现在的编辑卡片；不想要就删除或撤销。
   - 乙：先是草稿。卡片里改，视图实时预览；点「应用」才写进特征树，算一步可撤销；点「取消」什么都不留。
   - **建议乙。** Onshape 和 SolidWorks 都是这样：对话框里调到满意再确认。半成品不会进特征树，不会连累后面的特征报错，也不会被 AI 看到。
   - 代价：要做「预览重建但不提交」，见下文实现表。顺带让编辑已有特征也实时预览（现在要点「应用」才看到）。
3. **插在哪**
   - 甲：插在当前查看的那一步后面（回滚到第 3 步时就插在第 3 步后），没回滚时插在末尾。
   - 乙：总是插在末尾。
   - **建议甲。** 这是 SolidWorks、Onshape 回滚棒的做法，也正是回滚这个功能的教学点：在历史中间插一步，看后面怎么跟着变。
   - 应用后，视图停在新特征这一步，「回到最新」照常可用。
4. **点了几个面或边，找不到一句共同描述时**
   - 甲：不改 DSL。提示「这几条边没有共同的描述：少选几条，或分成两个特征」。
   - 乙：选择器加一个 `any`，表示「下面这几组之一」，每组都已验证只选中一个；学习者怎么点都能存下来。
   - **建议乙，只作兜底**：先找共同描述（「沿 Z 的四条竖边」），找不到才用 `any`。
   - 理由：在专业软件里，学习者就是这样随手点几条边一起倒圆角。拒绝会让「不靠 AI」这条路走不通。
   - 代价：DSL、提示词、build123d 导出各加一处。提示词写明 AI 优先用语义条件，`any` 留给点选。

## 为什么

- 第一档做完后，不靠 AI 只能改已有的特征，不能新建。学习者从空白开始自己建一个零件这条路还是断的，而亲手走一遍「草图 → 拉伸 → 圆角 → 抽壳」是建模课最核心的练习。
- 选面、选边现在只能手写条件（法向、最靠外……），对新手太抽象。专业软件里是直接点；Onshape 的特征对话框里有一个「选择框」，点哪个面就进哪个框。
- 我们和专业软件的区别：点选不存成内部编号，而是翻译成看得懂、改了尺寸也照样选得对的语义条件。学习者点四条竖边，卡片里写出来的是「沿 Z · 来自 拉伸1 · 4 条」。这本身就在教「选择的意图」，也正是拓扑命名问题的解法。
- 选择器的合成和验证已经有了：标注里的 `uniqueFaceSelector` / `uniqueEdgeSelector`（`app/src/studio/kernel/select.ts`）。这次只是把它从「单个」扩到「一组」，并接到编辑卡片上。

## 拟定的决定（不需要你拍板，有意见可以改）

| 问题 | 决定 | 理由 |
| --- | --- | --- |
| 菜单里的顺序 | 按用途分组，组内按学习地图的顺序：草图；加料（拉伸、旋转、扫掠、放样）；切除（拉伸切除、孔）；修饰（圆角、倒角、抽壳、拔模）；复制（线性阵列、圆周阵列、镜像）。每项有图标、一句话说明 | 图标和「工具图鉴」一致（`OpIcon`）；「拉伸切除」单列，因为 SolidWorks 学习者认这个名字 |
| 前提不满足 | 菜单里置灰，并写出原因：「先新建一个草图」「至少要两个草图」「还没有实体」 | 不让学习者点进去才报错 |
| id 和名字 | id 自动取 `fillet2` 这种第一个没用过的；名字留空，显示为「圆角2」；设计意图留空，可以在卡片里写 | 和 AI 建的特征同一套规则（`displayName`） |
| 默认值 | 见下表：在当前实体上直接能建出来，尺寸按实体包围盒取整 | 一打开就能看到效果，再慢慢改 |
| 选择框 | 卡片里每个选面、选边的字段（`edges`、`faces`、`open`、`on.face`、`not`）都是一个选择框。同一时间只有一个是激活的（主色描边）；单击它激活。圆角、倒角、抽壳、拔模新建时，第一个选择框自动激活 | Onshape 的做法；一个框激活时，点击就不会被当成标注或测量 |
| 点选时视图显示什么 | 显示这个特征之前的实体（它的输入），而不是预览结果；框失去焦点后再显示预览 | 圆角预览里原来的棱已经没了，点不到；编辑中间某个特征时，要选的也是它之前的几何 |
| 单击 | 加入或移出这个框（再点一次就取消）；Esc 或点空白处结束点选 | 和测量的点选一致 |
| 在选边框里点一个面 | 等于选这个面的所有边，存成 `{ faces: <面的选择器> }` | Onshape 圆角就是这样；「顶面一圈倒圆角」一下就选中 |
| `expect` | 总是填成选中的个数，在卡片里显示为一个可以去掉的条件「预期个数 4」 | 和标注一致。上游改尺寸后选中数量一变，就当场报错并列出候选，不会悄悄选错 |
| 点选和手写条件的关系 | 点选生成条件，条件照常可以手改；手改后用 `locate` 重新算出选中了哪些，框里的列表跟着变 | 一份数据（选择器），两种编辑方式 |
| 按位置选的 | 只能靠 `near` 才唯一时，框里那一项标出「按位置选的，改尺寸后可能选错」 | 不藏风险 |
| 撤销 | 应用 = 一步撤销（`editTree` 已有 checkpoint）；取消不留痕迹；切换查看哪一步不算 | 和现在的编辑卡片一致 |
| AI 回复中 | 「＋ 新建特征」和「应用」禁用；有没应用的草稿时发消息，先提示「先应用或取消正在新建的特征」 | 两边同时改特征树会互相覆盖 |
| AI 之后看到什么 | 照旧每条消息附整棵特征树（`statePrompt`）。另加一行「自上次回复以来，学习者手动做了：新建 圆角2（fillet2）；改了 拉伸1 的 distance」 | AI 不会把学习者亲手加的东西当成异常改掉，回复时也能接着讲 |

## 交互

1. **新建**：点「＋ 新建特征」→ 选「圆角」→ 特征树里在插入位置出现一行「圆角2（草稿）」，旁边打开卡片。卡片和编辑卡片相同，标题后多一个「新建」标记。
2. **点选**：边的选择框已激活，视图显示输入实体，提示「在模型上点要倒圆角的边」。
   - 点一条竖边：框里出现「① 直线边 · 沿 Z · 来自 拉伸1」，下面的条件变成 `沿 Z · 来自 拉伸1 · 最靠外 +X+Y …`（内核验证过只选中这一条）。
   - 再点三条竖边：条件合并成「平行于 Z · 来自 拉伸1 · 预期个数 4」。
3. **预览**：点一下卡片里的半径，框失去焦点，视图显示圆角后的预览。改 r 时，停止输入 300 ms 后重建预览。
4. **应用**：写进特征树，可以撤销；卡片转为普通编辑卡片。
5. **从标注卡片来**：在模型上点了一个平面后，卡片上多两个按钮：
   - 「在这个面上画草图」：新建草图，`on.face` 填这个面的选择器，第一个图形放在点击处（用标注已有的草图坐标；斜面见斜面方案）。
   - 「在这里打孔」：新建孔，`on` 同上，`at` 为点击处。

## 每种特征的默认值

记号：B = 插入位置之前的实体包围盒；「最上面的面」= `{ normal: "+Z", extreme: "+Z", expect: 1 }`；尺寸取整到 1、2、5、10 这样的整数。

| 特征 | 默认值 | 前提 |
| --- | --- | --- |
| 草图 | 有实体：贴在最上面的面；选不出唯一一个时，改用 XY 基准面并偏移到 B 的顶面。没有实体：XY 基准面。图形是一个居中的矩形，宽和高约为 B 的一半（没有实体时 40×30） | 无 |
| 拉伸 | 草图 = 最近一个还没被用过的草图（都用过就用最近的一个）；距离 = B 最小边的一半（没有实体时 10）；加料 | 有草图 |
| 拉伸切除 | 同上，`mode: cut`，距离 = B 高度的一半 | 有草图、有实体 |
| 旋转 | 草图同上；轴：草图在 XZ、YZ 上时用 Z，在 XY 上时用 Y；360° | 有草图 |
| 孔 | `on` = 最上面的面；`at = [[0, 0]]`；`standard = { size: "M4" }`（普通过孔），贯穿 | 有实体 |
| 圆角 | 选边框为空，自动激活；r = 1 | 有实体 |
| 倒角 | 同上；d = 1 | 有实体 |
| 抽壳 | 开口面 = 最上面的面（可以重新点选）；t = 2，且不超过 B 最小边的 1/5 | 有实体 |
| 拔模 | 选面框为空，自动激活；3°；中性面 XY | 有实体 |
| 线性阵列 | 要复制的 = 最近一个加料、切除或孔特征；+X；3 个；间距 = B 在 X 向的 1/4 | 前面有这类特征 |
| 圆周阵列 | 同上；绕 Z；6 个 | 同上 |
| 镜像 | 同上；YZ 基准面 | 同上 |
| 扫掠 | 路径画在 XZ 上：(0,0) → (0,30) → (30,30)，拐角 R5；截面 ⌀5 圆 | 无 |
| 放样 | 最近的两个草图 | 至少两个草图 |

- 默认值建不出来时（例如旋转的草图跨过了轴），卡片里就地显示内核的错误和建议，和 AI 建错时一样，不另做猜测。
- 图形的默认值沿用编辑卡片已有的 `NEW_SHAPE`（`app/src/studio/ui/feature-editor.tsx`），补上「轮廓」（polyline）。

## 点选怎么变成选择器

在输入实体上（插入位置之前的那一步）：

1. **一个**：直接用现有的 `uniqueFaceSelector` / `uniqueEdgeSelector`。
2. **一组**：先找这组共有的属性作为基础条件：来自哪个特征、类型、法向或方向、半径。然后依次试下面这些，取第一个恰好选中这一组的，再加 `expect: n`。
   - 只用基础条件；
   - 加「最靠外」（六个方向）；
   - 加「坐标」（这一组在某根轴上坐标相同）；
   - 加「排除最靠外的一圈」（如盒子示例里的 `{ not: { extreme: "+Z" } }`）。
3. **都不行**：如果待讨论第 4 条选乙，就用 `any: [每一项的唯一选择器]`；选甲，就提示学习者。

每个候选都在输入实体上实际跑一遍才算数，和标注一样。

## 分期

- **第一期**（本方案）：「＋ 新建特征」菜单、全部 13 种特征的默认值、草稿和实时预览、插在回滚位置、选择框点选（单个、一组、面代表它的边）、`expect`、标注卡片的两个快捷按钮、给 AI 的手动改动摘要。
- **第二期**（看用下来的情况再定）：顶部工具栏、指向某个条件时高亮它选中的、拖动手柄改距离、快捷键。

## 风险

- **预览的开销**：插在中间时，后面所有特征都要重建两次（预览和撤回）；刻字模型一次约 1 秒。用 300 ms 防抖，重建中再改就丢掉旧结果。
- **合成的条件比学习者想的宽**：比如点了四条竖边，得到「平行于 Z」。以后再加特征，可能多选中别的边。`expect` 会当场报错并列出候选，不会悄悄选错。
- **点选和标注、测量抢点击**：优先级写死，并且激活的框有明显的描边和提示。
- **AI 和手动交替改**：手动改动摘要 + AI 回复时禁用手动改动，两边不会同时写。

## 验收

- 单元测试：
  - 四个现成模型上，每种特征在末尾按默认值新建都能建出来（旋转、放样、扫掠这类有前提的写明前提）；
  - 盒子上点四条竖边，得到「平行于 Z、来自 拉伸1、预期 4」；只点前面两条，得到的条件里有 `extreme: "-Y"`；
  - 改了 L 之后，同一个合成条件仍然选中同一组边；
  - 回滚到第 2 步时新建，特征插在第 3 位；
  - 手动改动摘要：新增、删除、改字段各一例；
  - （若选乙）`any` 的解析、导出。
- 冒烟测试：
  - 空白开始，不用 AI 建出小盒子：草图 → 拉伸 → 圆角（点四条竖边）→ 抽壳 → 孔；体积正确；
  - 草稿取消后特征树不变；应用后撤销一次就回去；
  - 标注卡片上「在这里打孔」，孔在点击处。
- 浏览器实测：
  - 新手视角走一遍上面的小盒子，计时；
  - 之后对 AI 说「把壁厚改成 3」，它保留手动加的特征并在回复里提到它们。
