# 工作台：补齐常用特征（成形到面、薄壁、筋、拉伸拔模）

- 状态：已上线（2026-11-07，#19）
- 日期：2026-11-06
- 范围：给拉伸补「成形到下一面 / 成形到面」，加薄壁拉伸、筋，并补强已有的拔模
- 相关：`docs/specs/2026-11-06-studio-tools.md`（第一档）、`app/src/studio/dsl.ts`、`app/src/studio/kernel/build.ts`、`app/src/studio/codegen.ts`

## 先盘点：已经有的

已有的不再做，只在后面「补强」里提缺口：

- 拉伸：`direction: "both"` 就是两侧对称（中面）；`through: true` 是贯穿切除，两侧都穿。
- 拔模：已有，`op: "draft"`，可以选面、选中性面，用 `BRepOffsetAPI_DraftAngle`。
- 抽壳、孔、圆角、倒角、线性 / 圆周阵列、镜像、旋转、扫掠、放样：都有。

真正缺的有三样：

- 拉伸到一个面为止（「成形到」）；
- 等厚的薄壁；
- 筋。

另外，草图现在只有封闭图形（`polyline` 会自动闭合），画不了一条开放的线，而薄壁和筋都要从开放的线出发。

## 为什么

- **成形到下一面 / 成形到面**：真实零件里，立柱、凸台常常要「长到碰到上面那块板为止」。现在只能自己算距离；上面的板一改高度，柱子就不对了。这正是参数化的要点：设计意图写成「到那个面」，而不是写死一个数。
- **薄壁**：钣金样的支架、角钢、U 形槽、外壳侧壁都是等厚的。现在要自己算出内外两条轮廓，学习者算不对，模型也容易画错方向。
- **筋**：塑料件和铸件几乎都有加强筋（支架的三角筋、盒子里的十字筋）。现在要自己画出三角形，还得量到墙面的位置；筋的意义恰恰是「从一条线长到墙为止」。
- **拉伸拔模**：注塑件的凸台带锥度是常态。现在要先拉伸，再单独选侧面做拔模，两步才行。

## 已确认（2026-11-07，均按建议）

**F1. 先做哪几样、按什么顺序？**

- A. 全部四样一起做。
- B. 先做成形到面和薄壁，筋第二批，拉伸拔模最后。
- C. 只做成形到面和薄壁。

建议 B。前两样最常用、风险最小（探针都已跑通）；筋要新算法，单独一批好验证；拔模已经能用，只是不方便。

**F2. 开放的线怎么表示？**

- A. 草图里加一种新图形 `path`（开放的折线和圆弧，不能 `cut`）。
- B. 给 `polyline` 加 `closed: false`。

建议 A。`polyline` 现在的约定是「自动闭合」，模型已经学会了，改它的语义容易混。新类型名字就说明了是开放的；只有薄壁和筋能用它，用错时报错一句话就清楚。

## 建议的做法

| 问题 | 建议 | 理由 |
| --- | --- | --- |
| 成形到 | `extrude.until`：`"next"` 或 `{ face, offset? }`；有 `until` 时不填 `distance` | 和 SolidWorks 的「成形到下一面 / 成形到一面」一一对应 |
| 下一面怎么算 | 先拉得很长，再和实体求差（加料）或求交（切除），只留下贴着草图平面的那几块 | 全用三维布尔，稳；不用射线求交（这个 wasm 里没有 `IntCurvesFace_ShapeIntersector`） |
| 到指定面 | 用 replicad 的 `extrudeFaceUntil` | 探针：拉到 15° 斜面，体积完全对，11 ms |
| 薄壁 | `extrude.thin = { t, side? }`；`side` 取 `center`（缺省）/ `inside` / `outside` | 封闭轮廓和开放的线用同一个字段 |
| 薄壁的端头 | 开放的线两端平齐，不做圆头 | SolidWorks 和 build123d 的 `trace` 都是平头 |
| 筋 | 新特征 `op: "rib"`：`sketch`（一条 `path`），`t`，`flip?` | 只做「平行于草图」这一种；「垂直于草图」的筋就是薄壁加成形到下一面 |
| 筋的材料在线的哪一侧 | 自动：取被实体和线围住的那一侧；两侧都围住时报错，提示加 `flip` | 绝大多数情况不用想；不明确时让人明确说 |
| 拉伸拔模 | `extrude.draft?`（度，正值向内收），中性面就是草图平面 | 一步出锥形凸台 |
| 拔模的中性面 | `draft.neutral` 加一种写法 `{ face }`（选一个平面） | 中性面常常是分型面，而分型面不一定在基准面上 |

## 1. 成形到下一面 / 成形到面（第一批）

**DSL**（`extrude` 上加）：

```ts
until: z.union([
  z.literal("next").describe("一直长到碰到实体为止（加料），或切到这段材料穿出为止（切除）"),
  z.object({ face: FaceSelector, offset: Num.optional().describe("停在离这个面多远的地方，正值 = 还没到") }),
]).optional().describe("成形到：不用 distance"),
```

- `distance` 改为可选，用 refine 规定 `distance` 和 `until`、`through` 三者只能填一个。
- `direction` 照常有效。`both` 和 `until` 不能一起用，报错时直接说明原因。

**内核做法**：

- **`"next"`，加料**：
  1. 把草图沿方向拉到 `bigLength`，得到 T。
  2. 算 `T.cut(body)`，拆成若干实体。
  3. 只留下和草图平面相接的那几块（包围盒的一端落在草图平面上）。
  4. 把留下的块和实体合并。
  这样得到的柱子正好长到第一个挡住它的面；挡住它的面是斜的、弯的都行。
- **`"next"`，切除**：做法同上，但换成 `T.intersect(body)`，留下贴着草图平面的那几块再切掉。也就是切到这段连续的材料穿出为止，像沉槽一直切到下一个空腔。
- **`{ face }`**：选面必须正好一个，而且要能把整个轮廓盖住，然后调用 `extrudeFaceUntil(profile, face, dir)`。
  - 盖不住或者方向不对时，报「这个面挡不住整个轮廓」，并列出候选面。
  - 有 `offset` 时：平面目标先把面沿法向平移；曲面目标不支持 `offset`。
- **面的来历**：
  - 侧面和端面由现有的 `classifyFaces` 判断，记为本特征生成的面。
  - 端面虽然和目标面共面，但它是新面，来历记为本特征。和 SolidWorks 一样，回滚到这一步时，端面会高亮成新面。
- **摘要**：例如「加料 成形到下一面（实际 32.0 mm）」。把实际长度写出来，学习者能和自己估的对一下。

**build123d 导出**：

- `"next"`：`extrude(sk, until=Until.NEXT, target=part)`。
- 平面目标：`split(extrude(sk, amount=BIG), bisect_by=Plane(<面>), keep=Keep.BOTTOM)`，用现有的 `faces()` 选择器写法选出这个面。
- 非平面目标：退成实际长度，并加注释「成形到曲面，按当前长度导出」。

**评测**：`up-to-next`。

> 做一个门字形：底板 80×60×8，两侧竖板厚 8、高 40，顶上盖一块 80×60×6 的顶板；在底板中心立一根 ⌀16 的圆柱，向上一直长到碰到顶板。

检查三点：

- 柱子的体积约等于 π·8²·40；
- 全部连成一个实体；
- 把参数里的竖板高度改成 60 以后，柱子跟着变长（同一棵树再重建一次）。

## 2. 薄壁拉伸（第一批）

**DSL**：

- `extrude` 上加：

  ```ts
  thin: z.object({
    t: Num.describe("壁厚"),
    side: z.enum(["center", "inside", "outside"]).optional().describe("厚度加在线的哪一侧：center = 两侧各一半（缺省）；封闭轮廓里 inside = 向里"),
  }).optional().describe("薄壁：只沿着轮廓线长出一圈等厚的壁"),
  ```

- 草图图形加 `path`：

  ```ts
  z.object({
    type: z.literal("path"),
    points: z.array(z.union([Vec2, z.object({ to: Vec2, via: Vec2 })])).min(2).describe("开放的线，依次连接，不自动闭合；只能用于薄壁和筋"),
  })
  ```

**内核做法**：

- **封闭轮廓**：
  - `Drawing.offset(+a).cut(Drawing.offset(-b))` 得到一圈带状区域，再按 `side` 取 a、b。
  - 探针：20×10 的矩形，向外、向内各偏 1，拉伸 5，体积 595.71，和理论值完全一致。
- **开放的线**：
  - replicad 的 `Drawing.offset` 碰到开放的线会返回空图形（探针报错「Trying to sketch an empty drawing」），所以直接用 `BRepOffsetAPI_MakeOffset(wire, Arc, IsOpenResult)`。
  - 探针：`IsOpenResult = false` 时，结果是一圈绕着线、两端是圆头的封闭轮廓，体积 314.6，理论值 315.7 减去拐角重叠，对得上。
  - 要平头：两侧各用 `IsOpenResult = true` 偏出一条开放的线，再用两条直线把端头封上。
- 有 `path` 的草图如果用在普通拉伸、旋转上，报错：「开放的线只能做薄壁或筋」。
- **面的来历**：内外壁和两个端面都是本特征生成的面，不用特别处理。
- **build123d 导出**：
  - 封闭轮廓：`offset(sk, a) - offset(sk, -b)`。
  - 开放的线：`trace(<线>, line_width=t)`，正好是平头。

**评测**：`thin-angle`。

> 用一条 L 形的线（横 40、竖 30，画在前视基准面上）做一根厚 3、长 50 的角钢，用薄壁拉伸，厚度向里。

检查：

- 包围盒是 40×50×30；
- 体积是 (40+30−3)×3×50；
- 树里不出现两条手算的轮廓线。

## 3. 筋（第二批）

**DSL**：

```ts
z.object({
  ...Base,
  op: z.literal("rib"),
  sketch: z.string().describe("只含一条 path 的草图；线的两端可以不碰到实体，会自动延长"),
  t: Num.describe("筋厚，在草图平面两侧各一半"),
  flip: z.boolean().optional().describe("材料长在线的另一侧（自动判断不明确时才用）"),
})
```

**内核做法**（探针已跑通）：

1. 把线两端延长到很远，在草图平面里取线的一侧，围成一个大四边形。
2. 沿草图法向拉成厚度为 `t` 的板，和实体的包围盒求交，再减去实体。
3. 拆成若干实体，只留下不碰到包围盒外框的那几块，也就是被实体和线围住的空腔。
4. 把留下的块和实体合并。

探针：

- L 形支架：底板 60×30×6，立板厚 6、高 50；筋从立板 40 高处斜到底板，厚 4。加上的体积 2312.0，正好是 34×34/2×4，只有一个实体，用时 53 ms。
- 内部的十字筋按同一条规则也成立（线横穿盒子，下面那一侧被四壁和底围住），还没跑探针，留给单元测试确认。

**判断材料长在哪一侧**：

- 两侧都试一遍，只有一侧有空腔就用那一侧。
- 两侧都有空腔时，报错并提示用 `flip`。缺省用离实体中心近的那一侧，`flip` 换到另一侧。
- 两侧都没有空腔，报「筋碰不到实体：线的两侧都没有被实体围住的地方」。

**面的来历**：筋的两个侧面和斜面都是本特征生成的面。

**build123d 导出**：

- 生成一个 Python 辅助函数 `rib(part, plane, points, t, flip=False)`，用同样的步骤实现（约 15 行，和已有的 `on_face` 一样放在文件开头）。
- 这样导出的代码仍然是参数化的，不是一段写死的轮廓。

**评测**：

- `gusset`：L 形支架加三角筋，题面同探针的尺寸。检查加上的体积，误差 1% 以内。
- `box-ribs`：开口盒子里加十字筋，筋高到盒子一半。检查连成一个实体，体积增加量对得上。

## 4. 拔模补强（第三批）

- **拉伸带拔模角**：`extrude.draft`。
  - 做法：先正常拉出工具体，再对它所有不平行于草图的侧面拔模，中性面就是草图平面；然后像现在一样做布尔。
  - 探针：
    - 矩形 20×20，拉 10、拔 5°，体积 3660.3，和棱台公式完全一致；
    - 圆角矩形也能做；
    - 单个圆柱侧面会失败（OpenCascade 处理闭合面的拔模有问题）。
  - 失败时退回放样：用原轮廓和向内偏移 `h·tanα` 的轮廓做一个直纹放样。现有的放样能做，偏移也能做。
  - 不用 `BRepFeat_MakeDPrism`：探针里加料时体积不变、切除时多切了十倍，不可靠。
- **中性面用一个平面**：`draft.neutral` 允许写 `{ face: FaceSelector }`，必须选中正好一个平面。
- **build123d 导出**：
  - 拉伸拔模：`extrude(sk, amount=h, taper=α)`，build123d 的 `extrude` 自带 `taper`。
  - 面作中性面：`draft(faces, Plane(<面>), α)`。

## 提示词和工具说明

每样加一两句：

- 「柱子要长到上面的板，用 `until: "next"`，不要自己算距离」
- 「等厚的壁用 `thin`；开放的线用 `path`」
- 「加强筋用 `rib`，线不用碰到墙」
- 「注塑凸台用 `extrude.draft`」

在编辑卡片里，`until`、`thin`、`draft` 由表单按 schema 自动出现，不用额外做界面。

## 验收

- **单元测试**：
  - 成形到下一面：加料和切除；目标面是斜面或圆柱面；`direction` 是 `reverse`；
  - `until` 和 `distance` 互斥时报错；
  - 薄壁：封闭轮廓三种 `side` 的体积；开放的 L 线体积，平头；
  - `path` 用在普通拉伸上报错；
  - 筋：三角筋体积；十字筋；两侧都有空腔时报错；碰不到实体时报错；
  - 拉伸拔模：矩形符合棱台公式；圆形走放样兜底；
  - build123d 导出含 `Until.NEXT`、`trace(`、`taper=`、`def rib(`。
- **冒烟测试**：从现成模型加一个成形到下一面的拉伸，在编辑卡片里看到「成形到」字段。
- **真模型评测**：新增 `up-to-next`、`thin-angle`、`gusset`，原有 17 道不退步。

## 风险

- 「下一面」靠「贴着草图平面的那几块」来判断。草图平面本身落在实体表面上时（在顶面上往上长），贴着它的块就是想要的那块；草图平面落在实体内部时，切除的结果可能不符合直觉。这种情况先报错，提示「草图在实体里面，用 distance」。
- 开放的线偏移，在线自己相交或拐角太尖时，`MakeOffset` 可能失败。失败时报「线拐角太尖或自交」，不去猜。
- 筋的空腔判断依赖包围盒。实体是多个不相连的块时可能误判，所以只在实体只有一个块时允许做筋。
- 新特征越多，提示词越长。每样只加一两句，用评测守住原有的题。
