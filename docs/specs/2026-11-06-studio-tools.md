## 为什么

- 工作台原来只能靠对话改模型，参数面板只有一串名字和数字。学习者看不出 `pcd` 是什么，也没法自己动手改一个特征。参数化建模的手感，正是自己改一个数、看整棵树跟着变。
- 测量、剖视、标准孔、斜面草图是专业软件里天天要用的工具。没有它们，很多常见零件说不清，也做不出来。

## 已定的决定

| 问题 | 决定 | 理由 |
| --- | --- | --- |
| 参数说明谁来写 | 模型在 `set_params` 时用 `notes` 写一句；现成的特征树手写 | 学习者看到的就是建模时的意图；不另开界面 |
| 参数面板显示什么 | 说明直接显示；下面一行灰字写「用在：草图1 · 矩形宽、拉伸1 · 距离」；指向参数时，模型上高亮它影响的特征（含阵列、镜像出来的） | 名字、意思、位置三者对上号；用到哪里由特征树自动算出，不会和模型对不上 |
| 单击特征树的一行做什么 | 打开编辑卡片（原来是回滚）；回滚移到卡片里的「眼睛」按钮 | 编辑比回滚常用；悬停仍然只看详情 |
| 编辑卡片怎么来 | 按每种特征的 zod schema 自动生成表单：数值可以写表达式，枚举用下拉，特征引用列出前面的特征，选择器只显示已有条件、可增删 | 和模型用的 `edit_feature` 同一套字段，不用为每种特征手写 |
| 改完怎么生效 | 「应用」整体替换这个特征（去掉的字段就真的去掉），可以撤销 | 与 `edit_feature` 的合并语义不同：手改时清空一个字段就是想去掉它 |
| 压缩 | 特征加 `suppressed`；用到被压缩特征的特征一起压缩（和 SolidWorks 一样），其余照常重建 | 压缩种子孔时，阵列跟着不见，而不是报错 |
| 上移、下移 | 不能移到它用到的特征前面，也不能移到用它的特征后面 | 不产生悬空引用 |
| 删除 | 立即删除，提示里可以撤销；有后续特征引用它时，先说明，再给「连同它们一起删除」 | 可撤销的操作不弹确认 |
| 测量 | 视图右侧的工具栏开关测量模式。点一个面或边看它的尺寸，再点一个看两者之间：最短距离（画出来）、夹角、平行面间距、圆心距或轴线间距。Esc 退出 | 由内核用 BRepExtrema 精确计算，不是按网格估算 |
| 剖视 | 沿 X / Y / Z 切开，滑块调位置，可以保留另一侧；切口涂实心灰色 | 复用拆解页已有的剖切材质；剖开后点选只会选到留下的那一侧 |
| 标准孔 | `hole.standard = { size, fit, head }`，按表定孔径、沉孔和埋头锥口；螺纹孔钻攻丝底孔，在孔口和孔底画虚线圈表示装饰螺纹 | 学习者说「M3 沉头孔」时不用查表；真实螺纹几何太重，先做装饰螺纹 |
| 斜面上的草图 | `on.face` 选中的平面与 `plane` 不平行时，草图就贴在这个面上：原点在面的中心，x 沿面内的水平方向，y 沿面往上，法向朝外 | 规则只有一句，模型和学习者都能推出坐标；文字从外面看是正的 |
| 倾斜基准面 | `on.tilt = { axis, angle }`：把（平移后的）基准面绕过原点的坐标轴转一个角度 | 在还没有斜面的时候先建出斜的特征 |

## 标准孔的数值

见 `app/src/studio/holes.ts`：

- 过孔：ISO 273 中等系列（普通）和精密系列（精配）。
- 攻丝底孔：粗牙螺纹。
- 沉孔：按 ISO 4762 内六角圆柱头螺钉的常用值。
- 埋头锥口：按 ISO 10642 沉头螺钉的常用值。

这些是参考值，实际零件以螺钉供应商的资料为准。

## 实现中发现并处理的

- **汉字刻字的笔画合并**：
  - 原来用 replicad 的二维布尔把重叠笔画并起来。全量扫描常用字时，约 5% 的字（如「海」「客」「编」）直接报错。
  - 有的字虽然没报错，却悄悄丢了笔画：「坡鞍俺霸健」的面积少了 32%。
  - 现在笔画在二维里只挖掉各自的孔，拉伸成实体后再用 OpenCascade 的三维布尔合并（`mergeOverlaps`）。
  - 和按字体本身的非零环绕规则算出的面积逐字对照，误差在 0.1% 左右。
- **全量校验**：ASCII 94 个、GB2312 一级汉字 3755 个，逐字刻出来（凸字）和字体非零规则的面积对比，全部能建、误差都在 1% 以内，大多在 0.3% 以内。修之前，约 5% 的字报错，另有几十个字少了 2%–74% 的面积。
- **和自己相交的轮廓**：「4」「&」「;」「,」「量」的轮廓自己相交，字腔原来被填上了（「4」的三角形没了）。现在在交点处拆成简单的环，按环绕数决定哪些是孔。
- **刻字的内存**：两个样条侧壁相交的三维布尔，在这个 wasm 版本里每个字让堆涨几十 MB，而且不会回落。刻五个汉字的特征每重建一次就涨约 200 MB。
  - 参与合并的笔画改画成折线（离曲线 5 µm 以内），现在约 40 MB，五个汉字的刻字从 5.6 秒降到约 2.5 秒。合并这些折线笔画时不能做同域合并（SimplifyResult），否则会丢掉整笔（「偶」只剩四分之一）。
  - 剩下的增长靠已有的机制兜底：堆超过 1400 MB 时重启 Worker。
- **压缩种子特征**：原来压缩一个孔，阵列会报错，后面的特征全部跳过。现在阵列跟着压缩，后面照常重建。

## 验收

- 单元测试：
  - 参数「用在哪里」和影响的特征，包括阵列出来的；
  - 参数说明的增删；
  - 整体替换、上下移的限制；
  - 压缩连带依赖它的特征；
  - 测量：平行面间距、轴线间距、整圆边直径；
  - 标准孔的尺寸、装饰螺纹圈；
  - 斜面草图的位置、倾斜基准面的包围盒；
  - build123d 导出 `on_face` 和 `Rot`。
- 冒烟测试：单击特征打开编辑卡片并应用；参数说明和用处；测量出结果，Esc 退出；剖视面板出现，画面有内容。
- 真模型评测：新增「四角 M4 螺纹孔」和「斜面中心的凸台」两道，原来 15 道不退步。
