# 工作台：尺寸标在模型上，参数连线到模型

- 状态：已上线（2026-11-07，#15）
- 日期：2026-11-07
- 范围：

## 已确认（2026-11-07，均按建议）

1. **「显示尺寸」默认开还是关**
   - 甲：默认关。平时模型是干净的；指向参数或特征树的一行时，只标出相关的尺寸；需要时打开开关，一直标着主要尺寸。
   - 乙：默认开。一打开模型就标着主要尺寸。
   - **建议甲。** 例子：打开法兰盘，默认看到的是干净的盘子。指向参数 `pcd`，盘上出现一个虚线圆和「⌀90（pcd）」，一根细线从参数行连到这个标签。要截图分享时，再打开开关。一直开着时，有十几个标签压在模型上，看形状反而费劲。
2. **轮廓里没有名字的数，要不要让助教也定成参数**
   - 背景：助教画轮廓时常写 `R-11.2`、`Hn+36.5` 这样的点坐标（瓶颈往里收 11.2）。这类「参数加一个数」算出来的位置，模型上没法标成一个能看懂的尺寸，只能在特征卡片里列成「由公式算出」。
   - 甲：提示词要求助教把决定形状的数都定成参数并写说明，例如 `neck = 11.2`「瓶颈往里收的量」。参数面板会变长，比如瓶子从 6 个参数变成 9 个，但每个数都能在模型上指出来、单击改。
   - 乙：不改，这类数只在卡片里列出，让学习者通过助教来改。
   - **建议甲。** 「看得懂」比参数表短更重要。三点圆弧的「经过点」除外，它只是为了让弧线经过那里，不是设计尺寸。

## 为什么

- 现在参数面板只写着名字、说明和「用在：瓶体半截面 · 轮廓点」。到底是模型上的哪一段，要自己猜。指向参数时虽然会高亮受影响的特征，但高亮的是整块面，不是那个尺寸。
- 专业软件的做法：SolidWorks 双击特征，模型上就显示它的尺寸，双击尺寸就能改；Onshape 也一样。尺寸和模型对上号，就是「看得懂」。
- 和「人 + AI」的分工一致：人在模型上看到尺寸，单击改一个数，最多两下点击；要改结构就交给助教。不引入新的操作模式。
- 之后的工程图要的也是这套尺寸，只是画在二维视图里。

## 已定的决定

| 问题 | 决定 | 理由 |
| --- | --- | --- |
| 在哪里算 | Worker 里的内核，新请求 `dimensions()`：一次返回所有建成功特征的尺寸，每次重建后算一次，前端缓存 | 只有内核知道解析后的草图平面、斜面坐标、选中了哪些边、阵列的种子在哪 |
| 显示哪些 | 只显示「设计尺寸」：单个参数、参数乘一个系数（`pcd/2`）、字面值；由公式算出的（`Rb-rb`、`R-11.2`）不标在模型上，在特征卡片里只读列出 | 公式算出来的位置只是推导结果；标出来既看不懂，也不该直接改 |
| 标签写法 | 绑定参数的写「W = 50」；系数的写「pcd/2 = 45」，能还原成整个参数时直接画整个参数（见下文）；字面值只写数 | 名字和数一起出现，参数面板和模型才对得上 |
| 白话名 | 有参数说明就用说明（「瓶身半径」），没有就用字段名（「矩形宽」「孔径」，沿用 `param-uses.ts` 的 `label`） | 一处写好，到处一致 |
| 颜色 | 指向的那组尺寸用强调色，标签和参数行同色；「显示尺寸」开关下的其他尺寸用前景色细线 | 一个强调色；颜色不是唯一信号，标签里有名字 |
| 连接线 | 指向参数行时，从这一行连到它在模型上的每个标签（最多 3 条），细线、强调色、`aria-hidden` | 用户提的「用线条对照到模型上」；只在指向时出现，不常驻 |
| 修改 | 单击标签弹出小输入框：绑定参数的改参数；字面值的改特征字段，可以「设为参数」；Enter 应用，Esc 取消；可以撤销 | 和参数面板、特征卡片同一套规则 |
| 被模型挡住时 | 尺寸线和标签画在最上层；被挡住的那段线变淡 | 不会找不到，也看得出它在模型后面 |

## 尺寸模型

```ts
type Dim = {
  id: string                    // "h1:at.0.0"
  feature: string               // 特征 id
  path: (string | number)[]     // 特征里的字段路径
  kind: "linear" | "diameter" | "radius" | "angle" | "count" | "callout"
  value: number                 // 按当前参数算出的值
  source:
    | { type: "param"; name: string }               // "W"
    | { type: "factor"; name: string; k: number }   // "pcd/2" → pcd，k = 0.5
    | { type: "literal" }                           // 12
    | { type: "derived"; text: string }             // "R-11.2"：不画，只给卡片
  label: string                 // 「瓶身半径」
  text: string                  // 标签上的字：「W = 50」「4×⌀8」「8×R4」「4×M4 螺纹孔」（个数在前，和图纸写法一致）
  geom:                         // 三维几何，毫米
    | { type: "line"; a: V3; b: V3; offset: V3 }    // 尺寸线两端、向外偏的方向（画延长线）
    | { type: "leader"; at: V3; dir: V3 }           // 引线：从 at 沿 dir 引出标签
    | { type: "circle"; center: V3; normal: V3; r: number }  // 节圆，虚线
    | { type: "arc"; center: V3; from: V3; to: V3 }          // 角度
  priority: number              // 参数 > 系数 > 字面值；同一特征里按字段顺序
}
```

- **分类只靠求值**，不解析语法：只含一个名字时，令其他参数不变，把这个名字取 0、1、2、7 求值；正比于它就是 `factor`，k = 取 1 时的值。探针（`app/.tmp/dims-probe/classify.ts`）的结果：

  | 写法 | 分类 |
  | --- | --- |
  | `W` | param |
  | `pcd/2`、`-L/2`、`2*r`、`L/4` | factor |
  | `12` | literal |
  | `Rb-rb`、`R-11.2`、`Rb-0.293*rb`、`Hn+36.5` | derived |

- **同一个值只标一次**：同一特征里，同一个参数、同一个方向的坐标出现多次（轮廓上好几个点都在 x = R），只标第一个。
- **不标的**：值为 0 的坐标和偏移；三点弧的 `via`；选择器里的数（`near`、`at`、`radius`）；文字内容；`count` 以外的整数开关字段。

## 每种特征怎么标

「外侧」= 偏出这个特征自己外框的 6%，至少 3 mm。

| 特征 · 字段 | 种类 | 画法 | 标签例 |
| --- | --- | --- | --- |
| 草图平面 `offset` | linear | 从基准面量到草图平面，沿法向，放在草图外框的一角 | 偏移 = 20 |
| `rect` 的 `w` / `h` | linear | 沿草图 x / y 画在矩形外侧 | L = 80 |
| `rect` 的 `r` | radius | 从右上角圆弧中点引出 | R5 |
| 图形的 `center` | linear | 从草图原点沿 x、y 各一条，为 0 的不标 | x = 20 |
| `circle` 的 `d` | diameter | 圆周上 45° 处引出 | ⌀40 |
| `polygon` 的 `d`、`sides` | diameter | 外接圆，标签合并 | ⌀30 · 6 边 |
| `slot` 的 `length` / `width` | linear | 总长沿槽的方向，宽横跨一端 | 40 · 宽 8 |
| `text` 的 `size` | callout | 文字外框左边引出 | 字号 7 |
| `polyline` 点的 x / y | linear | 坐标尺寸：x 从草图 y 轴（旋转特征就是转轴）水平量到点，y 从草图 x 轴竖直量到点 | Rb = 30 |
| `extrude` 的 `distance` | linear | 从草图平面沿拉伸方向，放在轮廓外框一角的外侧；`both` 标总长；`through` 改为引线写「贯穿」 | H = 30 |
| `revolve` 的 `angle` | angle | 不是 360° 时，在转轴旁画圆弧；360° 不标 | 270° |
| `hole` 的 `d` / `standard` / `depth` / 沉孔 | callout | 从第一个孔的孔口边缘引出，写成一条：孔径、个数、深度、沉孔 | 4×⌀8 ↧10，4×M4 螺纹孔 |
| `hole` 的 `at` | linear | 第一个孔心到草图原点的 x、y；`pcd/2` 这类见下一行 | x = 25 |
| 种子孔 `at` 为 `pcd/2`，后面有圆周阵列 | diameter | 过所有孔心画虚线圆，标直径：系数还原成整个参数 | ⌀90（pcd） |
| `fillet` 的 `r` / `chamfer` 的 `d` | callout | 从第一条选中边的中点，沿两侧面法向的平均方向引出 | 8×R4，4×C1 |
| `shell` 的 `t` | linear | 开口处最长的一条外缘，在其中点向里量 t | 壁厚 2 |
| `linear_pattern` 的 `count` / `spacing` | linear | 在种子和第一个复制品之间标间距，标签带个数 | 6× 间距 20 |
| `circular_pattern` 的 `count` / `angle` | count / angle | 在转轴上写个数；不是 360° 时画圆弧 | 6× 均布 |
| `draft` 的 `angle` | angle | 从第一个选中面的中心引出 | 拔模 3° |
| `mirror` / 中性面的 `offset` | linear | 同草图平面偏移 | 偏移 = 10 |
| `sweep` / `loft` | — | 第一期不标，由它们用到的草图自己标 | |

- **草图的尺寸画在草图平面上。** 拉伸后，它们就落在实体的底面或顶面上，例如盒子的 L、W 标在底面一圈外侧。
- **斜面草图**用 `on.face` 解析出的坐标系（`ResolvedPlane` 的 origin、x、y），和草图实际落点一致。
- **阵列复制出来的不再标**：种子的尺寸代表全部，个数写在标签里。

## 显示

1. **指向参数面板的一行**
   - 模型上画出这个参数的全部尺寸，包括通过别的参数间接用到的，规则沿用 `drivenBy`。
   - 从这一行连线到每个标签：贝塞尔曲线，2px，强调色。一个参数在模型上有多个尺寸时，最多连 3 条，参数行里写「另外 2 处」。
   - 标签不在视野里（被转到了背面或画面外）时不连线，参数行里写「1 处不在视野里」。
2. **指向特征树的一行**：画出这一步的设计尺寸，不连线。特征卡片里的尺寸列表也一样，见 `2026-11-07-studio-feature-card.md`。
3. **「显示尺寸」开关**
   - 放在视图右侧工具栏，在测量、剖视下面。
   - 打开后显示当前查看的那一步之前所有特征的设计尺寸，最多 12 个，按优先级取。
   - 被截掉的不显示；工具栏的提示写「显示了 12 / 20 个」。
- **尺寸线**：沿用测量的线材质（`kit.dimension`，`LineSegments2`），加箭头、两条延长线，标签用 CSS2D。
  - 标签是 `<button>`，样式和测量的标签一致：指向的这组是主色底，其余是背景色底加细边框。
  - 两个标签在屏幕上重叠时，后一个沿尺寸线法向挪一个标签高度，最多挪两次；还重叠就只留优先级高的。
- **被挡住**：画两遍。一遍做深度测试，正常粗细；一遍不做深度测试，35% 不透明。被模型挡住的那段线就变淡，标签总在最上层。
- **剖视打开时**：只画落在留下那一侧的尺寸。

## 单击就地修改

- 单击标签，打开一个小浮层（kit 的 Popover），里面有：
  - 白话名和说明，例如「瓶身半径」；
  - 名字和输入框，例如「R」；
  - 「R 还用在 3 处：瓶体半截面 · 轮廓点、瓶口 · 直径……」。
- **绑定参数的**：改参数，走 `setParam`。系数的（`pcd/2 = 45`），输入框里改的是 `pcd`，提示「这里显示的是 pcd 的一半」。
- **字面值的**：改特征里这个字段，用新的 `setFieldAt(tree, featureId, path, value)`，内部走 `replaceFeature`。浮层里有「设为参数」：
  - 新建一个参数，名字缺省是「特征 id_字段」（如 `fil1_r`），可以改；值就是当前值；说明就是白话名。
  - 字段改写成这个参数名。
- Enter 应用，Esc 取消，点浮层外面等于取消。重建失败时，错误留在浮层里，不关闭，例如「圆角太大：R12 超过了边长的一半」。
- 每次应用都是一步撤销（`editTree` / `setParam` 已有 checkpoint）。
- 助教回复期间，标签不能点，提示「助教正在改模型」，和特征卡片一致。

## 性能、手机、可访问性

- **性能**
  - 尺寸在每次重建后算一次，不挡显示。目标：四个现成模型在 30 ms 内，刻字模型在 150 ms 内（文字只标字号）。
  - 圆角、抽壳要在输入实体上重新解析一次选择器，有了按哈希列面和边（`kernel/topo.ts`），每次都在 10 ms 以内。
  - 前端只画当前要显示的那组，最多十几个对象；连接线在相机变化时用 `requestAnimationFrame` 跟着更新，只在指向期间运行。
- **手机**（宽度小于 768）
  - 没有悬停：点参数行的输入框时，模型上显示它的尺寸。
  - 右侧面板盖住视图时不画连接线。
  - 单击标签打开 BottomSheet，而不是浮层。
  - 标签的点击区域至少 44px，可见部分仍然是小标签。
- **可访问性**
  - 标签按钮的 `aria-label` 写全，例如「瓶身半径 R，30 毫米，单击修改」。
  - 连接线和尺寸线都是 `aria-hidden`。
  - 读屏用户在参数面板和特征卡片的尺寸列表里有同样的信息和操作。
  - 减少动态效果时，连接线不做出现动画。

## 验收

- **单元测试**
  - 分类：上面探针表里的每一行。
  - 盒子（`box-fillet-first`）的尺寸：L、W 画在底面外侧，两端相距 60、40；H 沿 Z 量 30；「N×R4」引线起点在一条被圆角的边上；壁厚 2.5 的两端相距 2.5。
  - 法兰：节圆的半径是 45，标签是「⌀90（pcd）」；「6× 均布」；孔标「⌀8」；倒角「C1」。
  - 瓶子类轮廓：`Rb` 是从转轴量起的水平尺寸，`R-11.2` 是 derived，不在要画的列表里。
  - `setFieldAt` 只改这一个字段；`promoteToParam` 新增参数和说明，字段改成参数名，模型不变。
- **冒烟测试**
  - 指向参数 L：视图里出现「L = 60」的标签，连接线的 SVG 路径存在。
  - 单击标签，输入 70 回车，实体的 X 尺寸变成 70；撤销后恢复。
  - 指向特征树的「抽壳」，出现「壁厚 2.5」。
  - 打开「显示尺寸」，标签不超过 12 个。
- **浏览器实测**
  - 法兰、盒子、助教建的瓶子、刻字铭牌，亮色和暗色各截一张，看标签是否压住形状、连线是否清楚。
  - 手机宽度下，点参数能看到尺寸，点标签能改。
  - 重建后 30 ms 内拿到尺寸（四个现成模型）。

## 风险

- **标签挤在一起**：复杂零件的尺寸多。第一期靠「只标设计尺寸」「最多 12 个」「重叠就挪或丢」三条控制，不追求像工程图那样排得整齐。
- **助教的树里大多是公式**：如果助教习惯写 `R-11.2`，能标的尺寸就少。所以有「待确认」第 2 条；不改提示词时，至少特征卡片里能看到「由公式算出」的值。
- **后面的特征改掉了这块几何**：例如孔后来又被填上了，尺寸仍然画在原来的位置。尺寸讲的是那一步的意图，这样画没错，但看起来可能怪。指向特征时只画到那一步为止，可以缓解。
- **连线跟不上相机**：连线跟着 CSS2D 标签的屏幕位置走，旋转视图时每帧更新；只在指向期间运行，不常驻。
