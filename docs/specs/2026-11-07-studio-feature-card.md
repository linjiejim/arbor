- 状态：已实现（2026-11-07）
- 日期：2026-11-07
- 范围：
  1. 单击特征树的一行，打开的不再是全字段表单，而是一张讲「这一步」的卡片：做了什么、它的尺寸、它选了哪些面或边；

## 先回答：特征卡片和参数面板有什么不同

| | 右侧参数面板 | 左侧特征卡片 |
| --- | --- | --- |
| 讲什么 | 整个模型共用的几个「旋钮」，例如 L、W、pcd | 特征树里的一步 |
| 内容 | 名字、说明、用在哪几处 | 这一步做了什么、为什么；它的尺寸，包括没定成参数的；它选了哪些面或边 |
| 改一个数 | 所有用到它的地方一起变 | 绑定参数的尺寸，改的就是那个参数，卡片会提示「还用在 3 处」；没绑定的只改这一步 |
| 例子 | 改 `pcd`，6 个螺栓孔一起往外挪 | 打开「外圆角」：把 R4 改成 R3，或者重选要倒圆角的边 |

两边改同一个参数，效果完全一样，只是入口不同：参数面板从「名字」找到模型，卡片从「这一步」找到数。

**现在的编辑卡片为什么看不懂**：它把特征的 JSON 原样排成了表单。截图里「瓶体半截面」的「经过 `Rb-0.293*rb`」，是助教为了让圆角弧线经过那里算出来的点，不是给人看的设计尺寸。草图平面、选择条件、轮廓点这些字段，大多是实现细节。

## 已确认（2026-11-07，均按建议）

1. **原来的全字段表单删掉还是折起来**
   - 甲：删掉。完整内容在「代码」页能看到，结构性的改动交给助教。
   - 乙：折成卡片底部的「高级：全部字段」，默认收起。
   - **建议甲。** 例子：想把瓶子的轮廓改成两段弧，在表单里要改 7 个坐标且不能出错；对助教说一句「瓶肩改成两段弧」更快也更准。留着「高级」，等于留着一个看不懂、点进去容易改坏的入口，还要一直维护（约 600 行）。

## 为什么

- 用户的方向：主要靠助教建模，人要看得懂，能做定向修改。人负责「看、确认、改数字、改选择」，每个操作最多两下点击。
- 现在单击特征树的一行，得到的是十几个输入框，看不出哪个是关键尺寸，改了也不知道会怎样。
- 专业软件里，编辑一个特征看到的也是它的尺寸和选择（SolidWorks 的属性管理器、Onshape 的特征对话框），不是数据结构。

## 新卡片长什么样

以「外圆角」（`box-fillet-first` 的第 3 步）为例：

```
外圆角                                第 3 步 · 圆角
R4 · 8 条边
设计意图：除了顶面一圈，竖边和底边都倒圆角；放在抽壳之前……
尺寸
  圆角半径    r = 4                 ← 指向时模型上标出；单击就地改
选中的边
  8 条：除了最上面一圈以外的边        [在模型上重选]
───────────────────────────────────────────────
 👁  压缩  ⋯                          [让助教改这一步…]
```

以「瓶体半截面」（助教建的瓶子）为例：

```
瓶体半截面                           第 1 步 · 草图
前视基准面 XZ · 1 个轮廓（6 段直线、2 段圆弧）· 被「旋转1」用到
尺寸
  瓶身半径   R = 30
  瓶底圆角   rb = 5
  瓶颈高度   Hn = 120
  ▸ 由公式算出的 3 个（只读）
───────────────────────────────────────────────
 👁  压缩  ⋯                          [让助教改这一步…]
```

- **标题行**：图标、名字、第几步和类型。不再显示 id。
- **摘要**：内核的 `summary`，例如「R4 · 8 条边」「切除 深 5」。下面一行是设计意图（`intent`），没有就不显示。
- **尺寸**：用尺寸模型（见尺寸方案）列出这一步的设计尺寸，交互和模型上的标签完全一样。
  - 指向一行，模型上标出这个尺寸；单击就地修改。
  - 绑定参数的，行里显示参数名，提示还用在几处。
  - 「由公式算出」的默认收起，展开后只读，写成「瓶颈半径 = R-11.2 = 18.8」。
- **两个可以直接改的选项**：这是常见的定向修改，又不是数，所以单列出来：
  - 文字特征的「文字内容」，例如把刻的字改成自己的名字；
  - 标准孔的「规格」（M3 → M4）和「用途」（过孔、螺纹孔）。
  其余枚举（方向、加料或切除、草图平面）交给助教。
- **选中的面 / 边**：只有圆角、倒角、抽壳、拔模、贴面的草图和孔才有这一节。用白话写出选择条件，加上实际选中的数量，例如：
  - `{ not: { extreme: "+Z" } }` → 「除了最上面一圈以外的边」
  - `{ parallel: "Z", of: "ext1", expect: 4 }` → 「平行于 Z 的边 · 来自 拉伸1 · 4 条」
  - `{ normal: "+Z", extreme: "+Z" }` → 「最上面那个朝上的平面」
- **底栏**
  - 「在这一步查看」（眼睛，原来的回滚）；
  - 「压缩 / 解除压缩」；
  - 「⋯」菜单：上移、下移、删除；
  - 主按钮「让助教改这一步…」。
  - 删除照旧立即执行，提示里可以撤销。
- **出错的特征**：摘要换成错误和建议（来自重建报告），主按钮变成「让助教修这一步」。点了以后，对话框里预填「「外圆角」报错了：……，帮我改好」。
- **没有自己尺寸的**（整体镜像、放样）：写「这一步没有自己的尺寸」，以及它用到了哪些特征。

**上移、下移放进「⋯」，不删。** 平时很少用，不该占底栏；但「先圆角，还是先抽壳」这课正是靠交换顺序讲清楚的，学习者自己换一次印象最深。删除也放进「⋯」：它可以撤销，但会连带后面的特征报错，不该和「查看」挨着。

## 在模型上重选

1. 单击「在模型上重选」，「选中的边」这一节加上主色描边，提示「在模型上点要倒圆角的边，再点一次取消；点一个面等于选它的一圈边」。
2. 视图换成这个特征的**输入**，也就是它前一步的实体：圆角之后，原来的棱已经没了，点不到。当前选中的边高亮。
3. 每点一下，加入或移出一条。卡片里实时写出合成的条件，例如「平行于 Z · 来自 拉伸1 · 4 条 ✓」。
4. 「应用」：写回选择器，`expect` 填成个数，重建，算一步撤销。「取消」或 Esc 恢复原样。
- **合成规则**：
  - 单个：沿用 `uniqueFaceSelector` / `uniqueEdgeSelector`（`kernel/select.ts`）。
  - 一组：按 hand-modeling 方案「点选怎么变成选择器」第 2 条，先找共同属性（来自哪个特征、类型、方向、半径），再依次试加「最靠外」「坐标」「排除最靠外的一圈」。每个候选都在输入实体上实际跑一遍。
- **合成不出来时**：不在 DSL 里加 `any`。卡片提示「这几条边找不到一句共同的描述」，给两个选择：
  - 少选几条，或者分成两次圆角；
  - 「让助教来选」：把这几次点选作为标注（每条一个图钉）附到对话框，预填「「外圆角」改成选这几条边」。标注已经支持一条消息带多个图钉（最多 20 个）。
- **点击的优先级**：重选 > 测量 > 标注。重选期间，测量按钮和标注提示停用。
- 助教回复期间，「应用」「在模型上重选」「⋯」都停用，提示「助教正在改模型」。

## 让助教改这一步

- 单击后：对话框获得焦点，预填「改「外圆角」（fil1）：」，光标放在末尾；特征树里这一行保持选中。
- 不用改服务端：每条消息本来就附着整棵特征树（`statePrompt`），模型能从 id 找到这一步。
- 预填文字只是起头，学习者照常写要改什么，例如「改「外圆角」（fil1）：只倒竖边」。

## 分期

- **第一期**
  - 新卡片：摘要、意图、尺寸、两个直接可改的选项、选择的白话描述、在模型上重选（单个、一组、点面得一圈边）、底栏、出错时的样子、让助教改或修。
  - 删除旧表单（若「待确认」第 1 条选甲）。
  - 特征树悬停的预览层保留，底部提示改成「单击看尺寸和选择」。
- **第二期**
  - 指向「选中的边」这一行时，在模型上高亮它们（现在指向整行时高亮的是这一步生成的面）。
  - 卡片里显示这一步影响了后面哪些特征。
  - 手机上的重选（先只在桌面上开放，见风险）。

## 验收

- **单元测试**
  - 白话描述：四个现成模型里出现的每个选择器。
  - 一组的合成：盒子的四条竖边 → 「平行于 Z、来自 拉伸1、预期 4」；只点前面两条 → 条件里有 `extreme: "-Y"`；改了 L 以后，同一个条件仍然选中同一组。
  - 输入实体上的点选：在「外圆角」之前那一步点竖边，能合成出条件；在最新一步上点，同一条棱已经不存在。
- **冒烟测试**
  - 单击「外圆角」：卡片里有「R4」和「8 条：除了最上面一圈以外的边」，没有原来的输入框。
  - 卡片里把 r 改成 3：模型重建，撤销后恢复。
  - 「在模型上重选」：点一条竖边，卡片里条件变成单条；应用后摘要变成「1 条边」。
  - 「让助教改这一步」：对话框预填「改「外圆角」（fil1）：」。
  - 出错的特征：主按钮是「让助教修这一步」。
- **浏览器实测**
  - 用户视角：在助教建的瓶子上找到并改瓶身半径；在盒子上把圆角改成只倒竖边，看每件事是否两下点击以内。
  - 亮色、暗色、窄屏。

## 风险

- **能手改的变少了**：草图平面、轴、方向、加料或切除这些都不能在卡片里改，只能交给助教。这是有意的取舍。但要确认助教改这些足够可靠：现有 17 道评测里，有不少就在改这类结构。
- **合成的条件比想的宽**：例如点了四条竖边，得到「平行于 Z」。以后再加特征，可能多选中别的边。`expect` 会当场报错并列出候选，不会悄悄选错。
- **在输入实体上点选会让人迷惑**：视图「退回」到上一步。提示条要写明「现在显示的是倒圆角之前的样子」，应用或取消后立刻回到原来那一步。
- **手机上点选边很难**：边只有几个像素宽。第一期在窄屏上隐藏「在模型上重选」，改为「让助教来选」。
