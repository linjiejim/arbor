# Turnery：可打印性核对和 3MF 导出

- 状态：草稿，待确认
- 日期：2026-11-10
- 范围：需求核对表（`check`）加三种和 3D 打印有关的项：悬垂、最小壁厚、底面贴合；`export` 加 3MF。只在桌面版提供。
- 不在范围：切片、自动生成支撑、自动找最佳摆放方向、收缩和翘曲、注塑和 CNC 的可制造性。
- 相关：`2026-11-07-studio-checklist.md`（核对表）、`app/src/studio/kernel/check.ts`、`kernel/proximity.ts`（现有的薄壁和窄缝提醒）、课程「3D 打印：悬垂与摆放方向」（`content/lessons/print-overhang.part.ts`）

## 待确认

1. **悬垂按什么算「不通过」？** 建议按需要支撑的面积：超过 `area`（缺省 1 mm²）就不通过，结果里写出面积和最大角度。不建议「有任何一个超标的三角形就不通过」：曲面网格的边缘会有零星的超标三角形。
2. **桥接算不算悬垂？** 建议第一版算，并在结果里注明。孔的顶部、槽的顶面都是水平朝下的面，短跨度打印机能桥过去，但判断「短」需要找两端的支撑，放到后面做。
3. **最小壁厚每次重建都算吗？** 建议不：它要对面两两求最短距离，大零件会慢。和装配的检查一样延后算（`deferChecks`），结果按实体缓存，没算完时这一行显示「正在算」。
4. **3MF 里要不要带摆放方向？** 建议不带，按建模时的方向导出。

## 为什么

「一句话到能打印」差的最后一步是：做出来的东西打不打得出来。现在 agent 建完外壳，没人告诉它卡扣下面是悬空的、筋只有 0.3 mm。课程里已经讲了悬垂和摆放，判定方法是现成的，只是没接进内核。核对表的好处在这里同样成立：要求存进零件，改了参数自动重算。

## 设计

### 三种核对项

写法和现有的项一样，都有 `id` 和 `said`。都放进 `DESKTOP_CHECKS`。

| kind | 字段 | 怎么算 | 结果怎么写 |
| --- | --- | --- | --- |
| `overhang` | `max`：允许的悬垂角，缺省 45；`up`：打印时朝上的方向，缺省 `"+Z"`；`area`：允许的面积，缺省 1 | 在显示用的三角网格上逐个三角形算：`α = asin(−n·up)`，竖直的墙是 0°，水平朝下的面是 90°。`α > max + 0.5` 而且不贴在打印平台上（沿 `up` 的最低处 0.05 mm 以内）的三角形要支撑。和课程里的判定、0.5° 的余量一致 | 「要求 悬垂不超过 45°，实际 需要支撑 126 mm²（最大 90°）」。高亮这些三角形所在的面 |
| `min_wall` | `min`：最薄允许多少 mm | 推广现有的 `narrowSpot`：同一个实体上法向相对、中间是材料的两个面之间的最短距离，取最小值。只看平面和圆柱面 | 「要求 壁厚不小于 0.8 mm，实际 最薄 0.6 mm」。高亮那两个面 |
| `bed` | `up`；`min`：贴合面积至少多少 mm²，缺省不设（只报告） | 沿 `up` 最低处、法向朝下的平面的面积之和 | 「贴在平台上的面积 3 800 mm²」；设了 `min` 才有通过与否 |

多个零件时每个零件各算各的，`part` 字段指定只看哪一个；不写就看全部，结果里写出是哪个零件。上盖常常要翻过来打，所以 `up` 要能按零件写。

### 接进内核

- `dsl.ts`：`Check` 的 union 加三项；`check.ts`：`expectedOf` 和分派各加三个分支。
- `overhang` 和 `bed` 用每一步已经有的 `step.mesh`（带 `faceGroups`，能从三角形找回面）。装配里的零件没有这份网格时现算一份粗的。`runChecks` 的参数要多带一个网格。
- `min_wall`：`narrowSpot` 现在只拿这一步的新面去比，上限 60 对。新加一个不分新旧的入口，先用包围盒筛，上限 400 对；超过上限时结果里写「只查了最可能的 400 对」，不假装查全了。
- 界面不用改：核对表只认 `said / expected / actual / faces`。

### 给 agent 的说明

`check` 的工具说明和 `guide` 里加一段：用户说要 3D 打印时，建完加 `overhang` 和 `min_wall`；悬垂不过时先想能不能换个方向（`up`）或者加倒角，不要直接说「需要支撑」。壁厚的下限按喷嘴写：0.4 mm 喷嘴写 0.8。

### 3MF

- `export` 的格式加 `3mf`。它是 ZIP 加 XML，用现成的 `zipStore`，不加依赖。
- 单位毫米；每个零件一个 `<object>`，名字是零件名；三角形取和 STL 一样的精度（0.01 mm、0.1 rad）。
- 要一起改的地方约 8 处：`build.ts` 的 `exportBody`、`KernelHost` 和 `KernelCall` 的类型、`direct-kernel.ts`、`worker.ts`、`client.ts`、`protocol.ts` 的 `ExportFormat`、`catalog.ts` 的 schema、标题栏和主进程的导出菜单。

## 验收

- [ ] 一个 20 mm 的立方体：`overhang` 通过，`bed` 400 mm²。把它改成 T 形（上面比下面宽）：`overhang` 不通过，面积等于两侧下表面的面积（误差 1% 以内），高亮的是那两个面。
- [ ] 同一个 T 形，`up: "-Z"`（倒过来打）：通过。
- [ ] 45° 的倒角正好通过，46° 不通过（`max: 45`）。
- [ ] 外壳壁厚 2：`min_wall` 0.8 通过；参数改成 0.6：不通过，写出 0.6。
- [ ] 示例外壳（17 个特征，其中刻字有两百多个面）加上三项之后，重建的额外耗时不超过 0.5 秒；`min_wall` 不拖住其他项的显示。
- [ ] 导出的 3MF 能被 OrcaSlicer 或 Bambu Studio 打开，尺寸对，两个零件是两个对象。
- [ ] 用真实 agent 跑一遍：「做一个手机支架，要能不加支撑打印」，它加了 `overhang` 这一项并让它通过。

## 风险

- 曲面的悬垂靠网格判断，精度跟着网格走；面积的误差在百分之几。
- 「贴在平台上」只认最低的那一层；零件本来就要斜着打时，这些项的意义有限，说明里要写清楚。
- `min_wall` 只看平面和圆柱面，自由曲面的薄处查不到。
