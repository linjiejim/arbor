# Turnery：导入的 STEP 能选面

- 状态：草稿，待确认
- 日期：2026-11-10
- 范围：零件里用 `import` 读进来、作参考体的 STEP（开发板、元件），它的面能被选择器选中：用来测量、核对、把草图和孔贴上去；在窗口里也能点到它的面、在上面留备注。
- 不在范围：把 STEP 变回特征树；识别元件（「这是 USB-C 座」）；装配约束。
- 相关：`2026-11-07-turnery-desktop.md`「导入 STEP」和它「下一步」里的第 2 条、`app/src/studio/kernel/select.ts`、`build.ts` 的 `inspect`（已经能列出参考体的面）

## 待确认

1. **选择器里怎么写「选参考体的面」？** 建议沿用 `of`：`of` 写的是 `import` 特征的 id（或它的名字）时，就在这个参考体的面里选。`inspect` 现在就是这样，agent 已经会用。不新加字段。
2. **参考体上千个面时 `inspect` 怎么列？** 建议缺省只列面积最大的 40 个，其余按类型给个数；选择器加了 `near`、`normal`、`kind` 之后列出筛过的。
3. **在装配里改零件时，旁边的零件算不算参考体？** 建议算：`of` 写旁边零件的名字，也能选它的面。这样「上盖的止口对着底壳的内壁」可以直接量。
4. **窗口里点参考体的面，放在这一期还是下一期？** 建议这一期只做 agent 这一侧（第 1–3 步），窗口点选单独一步，可以晚一个版本。

## 为什么

围着开发板做外壳是 Turnery 最拿得出手的用法，现在卡在一个地方：板子是一个整体。agent 想把 USB 开口对准板上的座子，只能 `inspect` 把面列出来、读坐标、自己算，再把算出来的数写进草图。板子换一个版本，这些数就都错了。真实使用里 Codex 为了核对「板子底面到外壳内底 3 mm」绕了路，改成核对内腔总高（见桌面版 spec）。

代码里没有哪一行在「排除」参考体：选择器的候选面都来自实体，参考体从来不在里面。只有 `inspect` 为它开了一条临时的路。

## 设计

### 候选面从哪来

- 新增 `refFaces(step, name)`：`name` 是某个参考体（`step.refs`，以及在装配里改零件时的 `context`）的 id 或名字时，返回它的 `FaceInfo[]`，来源都记成这个参考体的 id。就是把 `inspect` 里那一段提出来。
- 每个参考体的 `FaceInfo` 算一次就缓存（按形状做 `WeakMap`）：开发板动辄上千个面，每个面都要积分求面积和面心。
- 选择器解析的入口统一判断：`sel.of` 指向参考体 → 用 `refFaces`；否则和现在一样用实体的面。`of` 指向 `mode: "add"` 或 `"cut"` 的导入时行为不变（那些面本来就在实体里）。

### 哪些地方接上

| 入口 | 现在 | 之后 |
| --- | --- | --- |
| `inspect faces / edges` | 能列，全列 | 缺省列面积最大的 40 个加分类统计 |
| `measure` 的 `face` / `edge` | 只能量实体的面；参考体只能整体量 | 能量参考体上的一个面：到实体的面、到另一个参考体的面 |
| `check` 的 `distance`、`gap`、`position` | 只认实体的面 | `face` 可以在参考体上：「板子底面到内底 3 mm」「USB 座的中心 X = 0」 |
| `sketch` / `hole` / `split` 的 `on.face` | 不行；没有实体时直接报错 | 可以贴在参考体的平面上；草图原点和方向的规则和贴在实体的斜面上一样 |
| `look` 的 `focus: { faces }`、`show` | 只认实体 | 能框住、高亮参考体的面 |
| `extrude` 的 `until: { face }` | 只认实体 | 可以长到参考体的面为止（柱子顶住板子底面） |
| 圆角、倒角、抽壳、拔模的选面选边 | 只认实体 | 不变。选到参考体时报「参考体的面只能用来量和定位，不能改」 |

`measure` 和 `check` 现在按面的 hash 在实体里找回面，参考体的面不在那张表里。改成解析之后直接带着 `FaceInfo` 往下传，不再经过 hash；不把两套面混进同一张表，避免编号撞上。

### 窗口（可以晚一步）

- 参考体现在不能点（`scene.ts`：「not pickable」）。给它的网格带上 `faceGroups`，点到时返回「参考体 `<名字>` 的面」，备注里的选择器写成 `{ of: "<id>", near: [x, y, z] }`。
- 参考体仍然半透明显示，鼠标指上去时那个面描边。

### 报错和说明

- `of` 指向参考体但选不到：列出离 `near` 最近的 5 个面（类型、法向、面心、面积），不是只说「没有」。
- STEP 的面很多是自由曲面，没有法向可比：这时提示用 `near` 加 `kind`。
- 改 `desktop/README.md` 的「已知局限」、`catalog.ts` 里关于导入的那段说明。

## 验收

用测试里已有的真实 STEP 文件，全部在真内核上跑。

- [ ] `measure`：参考体底面（`of: "board", normal: "-Z", extreme: "-Z"`）到外壳内底的距离，等于参数里的间隙。
- [ ] `check distance` 同一对面，期望 3：通过；把间隙参数改成 2：不通过，写出 2。
- [ ] `sketch` 的 `on.face` 贴在参考体的顶面上画一个圆，`extrude` 切除：孔的位置跟着参考体。把 `import` 的 `at` 改 5 mm，孔跟着走 5 mm。
- [ ] `extrude until` 到参考体底面的支撑柱：改板子的高度，柱子跟着变。
- [ ] `fillet` 的选边里写参考体：报错，说明原因。
- [ ] 一个 1 500 个面以上的 STEP：第一次解析选择器不超过 2 秒，之后同一个参考体不超过 50 毫秒；`inspect` 的输出不超过 60 行。
- [ ] 在装配里改上盖，`of: "底壳"` 选中底壳的内壁并量到距离。
- [ ] 真实 agent：给一块带 USB-C 的开发板，要求「外壳前壁的开口对准 USB 座，四周各留 0.5」。它用板上的面来定位开口，没有自己抄坐标；换一块 USB 位置不同的板，重建后开口跟着走。

## 分步

1. `refFaces` 加缓存；`inspect` 改用它并限制输出。
2. `measure`、`check`、`look focus`、`show` 接上。
3. `sketch` / `hole` / `split` 的 `on.face`、`extrude until` 接上；改说明和 README。
4. 窗口里点选和备注（可以晚一个版本）。

## 风险

- 参考体的面没有稳定的名字，只能靠位置和形状选（`near`、`normal`、`extreme`、`kind`）。板子换版本后同一个选择器可能选中别的面；`expect` 和核对项能发现数量不对，发现不了「选成了旁边那个」。
- 自由曲面多的模型（带线缆、弹片的）可选的平面少。
- 草图贴在参考体上之后，零件的重建依赖 STEP 文件的内容；文件丢了，这些特征会一起失败。报错要指向缺的文件。
