## 为什么

Jim 用 0.7.0 时提的：

1. 3D 视图上点已经加的备注圆点，要能重新编辑。
2. 选中一个零件时也能写备注，不一定要点到某个面或边，点选范围太小。
3. 备注模式下能在画面上画框、用画笔画出要说的地方，一次标得更大、更清楚。
4. 装配里选中零件，除了隐藏、隔离，还要能跳到单独的零件，和左栏点文件一样。
5. 左侧工具列要有快捷键，尽量单个字母。
6. 左栏的装配零件等能双击改名。
7. 右栏能拖宽、能折叠；左栏上下两块能调；顶栏、左右栏、状态栏东西太多，重新整理。
8. 时间线弱一些、少占地方，指上去再亮；装配里不要时间线。
9. 「3D / 工程图」挪到靠右，更新进度放在它左边。

读代码发现的：

- 同一个零件在装配里出现三次：左栏文件（文件名 shell）、左栏装配零件（实例名 底壳）、底部时间线（每个零件一步）。
- 颜色入口分三处：左栏圆点、时间线左端、拆件零件的小标签。
- 鼠标划过时间线时，步骤详情整块盖住右栏，右栏跟着跳。
- `update_note` 早就能改文字，但界面没接；改文字也不记进动态，agent 收不到提醒。
- 切到别的文件再回来，选中、隐藏、隔离、爆炸都丢了。
- 装配里「写一条」的备注显示「整个零件」。
- 对话固定在右侧时可用宽度按 224 / 380 写死算（`dockRoom`），左右栏能拖以后不对了。

## 设计

### 分工

左栏管「在哪、有什么」；中间是模型和直接操作；右栏显示选中东西的详情和文件级信息；顶栏是「在哪」和全局操作；状态栏只报现状。同一样东西只在一个地方，其他地方只链接过去。常驻的说明文字收进 ⓘ。

### 顶栏

`[红绿灯] [标志=回首页] [左栏开关] [‹ ›] 项目 / 装配 / 零件 …… [更新进度] [3D|工程图] [撤销 重做 导出] [对话] [接入 Agent] [右栏开关]`

- 标志本身就是回首页（⇧⌘H），去掉「Turnery」字样和房子按钮。
- 在装配里改零件时面包屑是「项目 / 盒子 / 底壳 · 在装配里」，点「盒子」回到装配，取代模型上方那条横幅。
- 「接入 Agent」只在还没有 agent 连过时出现在顶栏；连过以后从菜单或状态栏的 Agent 状态打开。

### 左栏

- 默认 224 px，拖右边 180–400 px，双击右边复位；⌘B 收起 / 展开；窗口窄于 1024 px 时默认收起。记在 localStorage。
- 上段「文件」：装配、零件、其他，和现在一样，加双击改名。
- 下段「结构」：当前文件由什么组成。装配列零件实例（颜色圆点、名字、文件名不同时第二行灰字、👁、⋯ 菜单：打开零件 / 在装配里改 / 隔离 / 改名 / 写备注）；拆过件的零件文件列拆出来的零件（颜色、👁）。「+ 零件」在这段的标题上。
- 两段之间的分隔条可拖，双击复位；两段标题可单独折叠。

### 3D 视图

- 工具列分三组：`V 查看与选择 · C 标注 · R 框选标注 · P 画笔标注 | M 测量 · X 剖视 · D 显示尺寸 | E 爆炸 · A 颜色 · 查看变更 | ? 快捷键`。「查看变更」从右上角挪进来。
- 时间线只在零件文件里有，装配里没有（装配的零件都在左栏「结构」里）。平时是一条矮的半透明细条（只有图标和「N 个特征」），鼠标移上去或键盘聚焦时亮起、展开名字；指向一步时在它上方弹小卡片（名字、类型、新面 / 改动面），不再盖住右栏；点一步才在右栏打开「详情」。
- 选中零件的工具条：`名字 · 打开零件 · 在装配里改 · 备注 | 隐藏 · 隔离 · 其余透明 | 定位步骤 · 清除`。

### 右栏

- 页签：`详情`（有选中时出现）`· 备注 n · 参数 · 动态 · 代码`。
- 默认 380 px，拖左边 300–560 px，双击复位；⌥⌘B 收成 40 px 的图标条（备注数、核对状态是徽标），点图标展开到那一页。
- 「详情」是原来的步骤详情，现在是真正的页签：点步骤、选中零件时切过去，关掉回到原来的页签。
- 动态页去掉和状态栏重复的 Agent 状态。
- 对话固定在右侧时的可用宽度按左右栏的实际宽度算。

### 状态栏

现状不变。有明确去处的项可以点：Agent 状态 → 动态；N 步没建成 → 第一个失败的步骤；核对 n/m → 参数页；N 条备注 → 备注页；第 N 版 → 动态。仍然不放独立按钮（改 D4）。

### 快捷键

| 键 | 作用 |
| --- | --- |
| V | 查看与选择（Esc 也回到这里） |
| C | 标注：点面或边；已经选中零件时，直接给选中的零件写备注 |
| R | 框选标注（一次性） |
| P | 画笔标注（一次性） |
| M | 测量 |
| X | 剖视 |
| D | 显示尺寸 |
| E | 爆炸 |
| A | 颜色 / 白模 |
| F | 适应窗口；有选中时对准选中的 |
| H / ⇧H | 隐藏选中 / 全部显示 |
| I | 隔离选中（再按一次恢复） |
| ↵ | 打开选中的零件（左栏结构里聚焦的一行也是） |
| Esc | 逐级退出：卡片 → 工具 → 选中 → 回滚的步骤 |
| ? | 快捷键一览 |
| ⌘B / ⌥⌘B | 左栏 / 右栏 |
| ⌘[ / ⌘] | 后退 / 前进 |

- 在输入框、对话框、菜单里不触发；带 ⌘ ⌃ ⌥ 的单字母不触发；按 `e.code` 判断，开着中文输入法也能用。
- 单字母不做成 Electron 菜单快捷键（会吃掉输入框里打的字），只在工具提示和「?」里写出来。
- 3D 视图和工具列是网页练习场共用的，快捷键两边都有；打开零件、后退前进、面板开关只在桌面版。

### 打开零件、后退前进

- 选中工具条「打开零件」、左栏结构的 ⋯ 菜单、双击模型上的零件、选中后按 ↵：单独打开它的零件文件（和左栏点文件一样）。子装配打开子装配本身。多选时不可用；STEP 参考件和标准件没有零件文件，说明原因。
- 「在装配里改」：原来时间线上的「改」。
- 窗口记一条打开文件的历史，⌘[ / ⌘] 和顶栏 ‹ › 前后走。
- 每个文件的选中、隐藏、隔离 / 其余透明、爆炸在这次运行里各自记住，切回来还是原样。

### 改名

- 左栏文件：双击或聚焦后按 F2，就地改（↵ 在一行上是打开）；↵ 确认，Esc 取消。改的是磁盘上的文件名（`rename_file`）：同时改项目里所有装配对它的引用、旁边的备注文件、已打开的文档；动态里记一条，agent 下一次调用收到「shell.turnery.json 改名为 底壳.turnery.json」。⌘Z 撤不了，提示里带「撤销」（再改回去）。
- 结构里的零件实例：双击或 F2，改装配里组件的 `name`（`rename_part`），⌘Z 能撤。引用旧名字的贴合（`mates.to.part`）、核对（`part`、`ref`、`a/b.part`）、备注、隔离和选中一起换；颜色写在组件上，不用换。复制出来的 `名字#2` 改的是组件名；拆件的 `名字/子件` 的子件名在零件文件里改。
- 步骤：双击时间线上的一步，右栏「详情」的标题变成输入框（标题上双击或 F2 也行）。
- 文件名按零件名用的组件（没写 `name` 的）跟着文件改名，引用它的贴合、核对、备注一样换成新名字。

### 备注

备注的对象：

| 对象 | 怎么留 | 图钉在哪 | agent 读到 |
| --- | --- | --- | --- |
| 面 / 边 | C 后单击（现有） | 点的地方 | 已验证的选择器（现有） |
| 零件 | 选中后「备注」或 C | 零件中心 | 零件名、组件、文件、包围盒 |
| 特征 | 详情里「给 agent 留备注」 | 这一步的面的中心 | 特征 id、名字 |
| 区域 | R 拖一个框 | 框里看得见的地方的中心 | 框里有哪些零件、特征、多少个面，模型坐标范围，视角，一张带框的截图 |
| 画笔 | P 在模型上画 | 笔画的中心 | 笔画经过哪些零件、特征，模型坐标范围，视角，一张带笔画的截图 |
| 整个文件 | 「写一条」（现有） | 没有 | — |

- 点图钉（任何工具下）打开和新建时一样的卡片：改文字、标为已处理、删除；对应的面、边、零件、框或笔画亮起。鼠标停在图钉上先看到文字。右栏备注列表里点文字也能改。
- 改文字记进动态（`note: "changed"`），agent 下一次调用会看到「备注有变化」。
- 框选、画笔都是一次性的：画完弹卡片，保存或取消后回到原来的工具，左键拖动照旧转视角。
- 框里有什么只算看得见的：在框里撒一片射线，被挡住、被剖掉、被隐藏的都不算。
- 画笔：每个点投到鼠标下的模型表面上，笔画贴着模型，转视角也跟着；落在模型外的点放在同一笔里模型点的平均深度上。笔画按模型坐标存，画成一条亮色的线。
- 截图：存在备注文件旁边的 `<名字>.notes/` 目录，`get_notes` 读到区域和画笔备注时，把截图一并给 agent（和 `look` 一样是图片）。
- 装配里写的备注记在装配文件里；agent 在装配里打开某个零件改时（带 context），`get_notes` 顺带列出装配里关于这个零件的备注。
- 整个文件的备注在装配里写「整个装配」。

## 决策

- **D1 改名改的是文件名**，不另设显示名：一个零件一个名字，agent 看到的路径和人看到的一致。代价是要连带改引用，所以由引擎一次改完。
- **D2 框选和画笔是一次性工具**：不改「左键拖动 = 转视角」的习惯。
- **D3 时间线悬停只弹小卡片**，点了才占用右栏（改掉 2026-11-07 的「指向就预览到右栏」）。
- **D4 状态栏有去处的项可以点**（扩大 2026-11-10 D4 的例外），仍不放独立按钮。
- **D5 装配里没有时间线**：零件统一在左栏「结构」。装配里回滚到某个零件之前的能力跟着去掉。
- **D6 对话固定栏的可用宽度**按左右栏实际宽度算（改 2026-11-10 D6 的写死值）。

## 实施记录（2026-11-11）

- 引擎：`rename_file`、`rename_part`（`desktop/core/rename.ts` 管名字怎么连带改）；`Files.rename`（桌面版不会盖掉已有文件，只改大小写时例外）。打开着的文件改名后重新打开，撤销历史、动态、agent 读到哪里都带过去。
- 备注：`PartNote.kind` 加 `parts`、`feature`、`region`；`pin: false` 表示没有图钉（没有面的步骤）。截图存成 `<名字>.notes/n<编号>.png`，备注里只记文件名，改名时整个目录跟着搬。`get_notes` 最多附最新的 4 张。
- 框选和画笔：`studio/region-pick.ts` 撒射线、算范围和图钉、拼截图；`studio/ui/sketch-layer.tsx` 是画的那一层和卡片。定位区域备注时飞回当时的视角，画笔画成 3D 线，框画在视图上，转一下视角框就消失。
- 每个文件记住的东西（选中、隐藏、隔离、爆炸、相机）只在这次运行里。
- 时间线平时只留图标和「N 个特征」；ⓘ 和颜色亮起时才出现。它们的弹层开着时时间线保持亮起（`timeline-lit` 变体，`src/index.css`），弹层淡出完才收起，免得弹层失去锚点跳到窗口角上。
- 双击一步改名：「要改名」由时间线自己记着，详情面板晚一拍才出来也会直接进入编辑，进入后清掉。网站的工作台也能这样改名。
- 网站 e2e 跟着新交互改：指一步看小卡片（第 N 步），点一步看详情，ⓘ 要先指向时间线。
- 文件改名（Codex 审查第 1 轮后）：先查完所有新路径（文件、备注、截图文件夹）再动；中途失败，已经移动的移回去、文件在原处重新打开。只改大小写时要确认是同一个文件（`Files.same`，比较 dev + inode），区分大小写的盘上不会盖掉另一个文件。装配里已经有零件叫新名字时拒绝。打开着的装配：这次改写不进它的撤销（撤销不能把文件改回去），之前的版本也换成新文件名（现在已经不用这个文件、撤销会把它带回来的也算；改写前顺带接上的外部保存也算）。改名失败、文件在原处重新打开后，窗口照常显示它。整零件 / 区域备注的 `parts` 跟着改名。
- 后退 / 前进：两次之间文件在加载（`doc` 为空）时不丢去向；改名进行中，文件以新名字重新打开算同一次访问（前面的记录不会被冲掉），成功后历史里的路径都换成新的，失败什么都不动。逻辑在 `desktop/visits.ts`。
- 每个文件的相机由窗口记着（`cameras`），视图在加载时被关掉再打开也能回到原来的角度。
- 空装配也显示「结构」区和 ＋（原来时间线左端的「添加零件」去掉后，这是唯一入口）。

已知未做：

- 删除备注不删它的截图（`Files` 没有删除接口）。
- 画了框或笔画以后不能再缩放，拖动也不转视角（画之前滚轮能缩放）；要换角度就 Esc 退出再来。
- 拉开（爆炸）时定位画笔备注，笔画还在装配位置。
- 定位框选备注时，窗口比例和当时不同，框只是大概的位置。
- 没有项目、装配又没打开时，零件改名找不到这个装配，不会跟着改。
